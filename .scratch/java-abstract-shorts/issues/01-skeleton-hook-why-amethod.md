# 01: 프로젝트 골격 + 도입·STEP 1 왜 필요할까·추상 메소드

**What to build:** static과 final 편과 같은 방식·템포(1.2배)로 추상 메소드와 추상 클래스 영상 프로젝트를 만든다. 상단 바 브랜드는 "자바 입문 abstract 정리"로 하고, "abstract"를 주황으로 강조한다.

도입("자바 입문 열두 번째, 추상 메소드와 추상 클래스")과 STEP 1을 대본 → 음성 → 화면까지 만든다. STEP 1은 두 장면이다.
- why: 상속 편 그대로의 일반 클래스 `Person`(몸체 있는 `hello()`)을 보여 주고, 몸체 줄을 강조해 "자식이 모두 오버라이딩해서 쓰이지 않는다"를 말한다. `new Person("서준")`이 되어 `서준 안녕`이 출력되는, 학생도 선생님도 아닌 어중간한 객체 문제를 보여 준다.
- amethod: 일반 메소드(`{ … }`)와 추상 메소드(`abstract void hello();`)를 비교 카드로 대비한다. 추상 메소드는 "자식이 꼭 완성하라"는 표시다.

이 장면들만으로 볼 수 있는 빌드가 나와야 한다.
