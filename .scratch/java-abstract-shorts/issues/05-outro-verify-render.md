# 05: 정리 장면 + 전체 검증·렌더링 + README

**What to build:** 정리 장면을 넣는다. 아래 6줄 목록 전체를 먼저 보여 주고, 나레이션이 각 항목을 말하는 순간 그 줄을 강조하며, 마지막에 "👍 구독 · 좋아요"를 보여 준다.

1. 추상 메소드 → 몸체 없이 `;`로 선언만
2. 추상 메소드가 있으면 클래스도 `abstract`
3. 추상 클래스는 `new` 불가
4. 자식은 추상 메소드를 꼭 오버라이딩
5. 아니면 자식도 `abstract`로 미루기
6. 필드·생성자·일반 메소드도 가질 수 있음

그다음 영상 전체를 검증하고 렌더링한 뒤, README의 영상 목록에 행을 추가한다.
