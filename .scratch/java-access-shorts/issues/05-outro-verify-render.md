**What to build:** 정리 장면을 만들고 영상 전체를 검증·렌더링한다.

- outro: 목록 전체를 먼저 보여 주고, 나레이션이 항목을 말하는 순간 `word_time()`으로 그 줄을 강조한다. 마지막에 "👍 구독 · 좋아요". 목록(대본 확정 시 조정 가능)

  2. 기본(아무것도 안 붙임): 같은 패키지까지
  3. `protected`: 같은 패키지 + 다른 패키지의 자식
  4. `public`: 어디서나
  5. 필드는 `private` + getter·setter(캡슐화)
  6. 오버라이딩은 범위를 좁힐 수 없다
