# 01: 프로젝트 골격 + 대본 전체 + 도입·STEP 1 try-catch

**What to build:** 스트림 편(19편)과 같은 방식·템포(1.2배)로 "예외" 영상 프로젝트를 만든다. 상단 바 브랜드는 "자바 입문 예외 정리"로 하고 "예외"를 주황으로 강조한다. 진행 표시는 5칸이다(2-1→2, 4-1→4).

19편의 출력 대조, 실행 중 오류 대조, 컴파일 오류 대조 헬퍼를 그대로 가져온다.

이 티켓에서 **영상 전체 대본**(hook, trycatch, kinds, order, finally, throw, throws, custom, outro)을 먼저 쓰고 길이(3분 이하, 목표 2분 30초 안팎)를 확인한다. 그다음 도입과 STEP 1을 대본 → 음성 → 화면까지 만든다.
- hook: "자바 입문 스무 번째, 예외". 150px 큰 제목 "예외"(`<em>` 주황). `10 / 0` 다음 줄 출력이 실행되지 않고 `ArithmeticException: / by zero`로 멈추는 실행 오류 상자. "지난 편들의 '실행 중 오류'가 바로 예외", 예외와 컴파일 오류의 구분
- trycatch: 같은 코드를 `try`에 넣고 `catch (ArithmeticException e)`로 잡으면 처리 문구 뒤 "끝"까지 출력. 예외가 난 줄 아래는 건너뛰고 `catch`로 넘어감

이 장면들만으로 볼 수 있는 빌드가 나와야 한다.
