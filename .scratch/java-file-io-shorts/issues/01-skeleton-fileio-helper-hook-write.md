# 01: 프로젝트 골격 + 헬퍼 확장 + 대본 전체 + 도입·STEP 1 쓰기

**What to build:** 예외 편(20편)과 같은 방식·템포(1.2배)로 "텍스트 파일 읽기·쓰기" 영상 프로젝트를 만든다. 상단 바 브랜드는 "자바 입문 파일 읽기·쓰기 정리"로 하고 "파일"을 주황으로 강조한다. 진행 표시는 5칸이다(1-1→1).

20편의 대조 헬퍼를 가져와 확장한다.
- 예제 프로그램을 예제마다 만든 임시 폴더 안에서 실행한다(저장소에 `scores.txt`가 생기지 않게)
- 실행이 끝난 뒤 임시 폴더의 `scores.txt` 내용을 읽어 기대 내용과 대조하고, 다르면 빌드를 멈춘다
- 화면에 "scores.txt" 파일 내용 상자를 실제 내용으로 그린다(줄 색은 민수 k1, 서준 k2, 지우 k3)
- 파일 입출력 클래스 import를 기본 import에 더한다

이 티켓에서 **영상 전체 대본**(hook, write, append, read, sum, except, files, outro)을 먼저 쓰고 길이(3분 이하)를 확인한다. 그다음 도입과 STEP 1을 대본 → 음성 → 화면까지 만든다.
- hook: "자바 입문 스물한 번째, 텍스트 파일 읽기·쓰기". 150px 큰 제목 "파일". 리스트 데이터는 프로그램이 끝나면 사라지고 파일은 남는다
- write: try-with-resources 괄호 안에서 `BufferedWriter`(`new FileWriter("scores.txt")`)를 열고, `write("민수,85")` + `newLine()`, 서준도 같은 방식으로 → 파일 두 줄. `FileWriter`는 파일을 열고 `BufferedWriter`는 감싸서 편하게 쓰게 함. 블록이 끝나면 자동으로 닫힘. `.note`: 이름만 쓰면 프로그램을 실행한 폴더에 생김
