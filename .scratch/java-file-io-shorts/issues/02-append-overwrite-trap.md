# 02: STEP 1-1 이어쓰기 + 덮어쓰기 함정

**What to build:** 기존 내용 뒤에 덧붙이는 이어쓰기와, `true`를 빠뜨려 덮어쓰는 함정을 보여 주는 장면.
- append: write 장면의 코드를 보이지 않는 사전 코드로 먼저 실행해 두 줄 파일을 만든 뒤, `new FileWriter("scores.txt", true)`로 `지우,78`을 덧붙임 → 파일 세 줄
- 함정: 같은 코드에서 `true`를 빼면 덮어써서 `지우,78` 한 줄만 남음. 덮어쓰기가 기본이고 이어쓰기는 직접 정해야 함
