# 02: STEP 2 물려받기 + STEP 3 오버라이딩

**What to build:** STEP 2에서는 Student에 `hello()`가 없어도 `s1.hello()`가 "민수 안녕"을 출력하는 것과, 부모 필드 `name`을 점으로 쓰는 것을 보여 준다. 자식만의 필드 `score`(민수·85)와 `subject`(서준·수학)도 보여 준다.
