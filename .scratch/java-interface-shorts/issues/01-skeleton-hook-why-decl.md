# 01: 프로젝트 골격 + 도입·STEP 1 왜 필요할까·선언

**What to build:** 추상 메소드와 추상 클래스 편(12편)과 같은 방식·템포(1.2배)로 인터페이스 영상 프로젝트를 만든다. 상단 바 브랜드는 "자바 입문 인터페이스 정리"로 하고, "인터페이스"를 주황으로 강조한다.

도입("자바 입문 열세 번째, 인터페이스")과 STEP 1을 대본 → 음성 → 화면까지 만든다. STEP 1은 두 장면이다.
- why: 서준은 가르치기도 하고 공부도 한다. 능력마다 부모 클래스를 두고 싶지만 `extends`는 하나만 된다(상속 편의 단일 상속). 코드 없이 개념 카드로 보여 준다. Teacher에서 두 부모로 가는 그림에 ✗를 표시하고, "extends는 하나만" 경고를 둔다.
- decl: `interface Studyable { void study(); }`를 보여 준다. 몸체 없는 메소드를 적은 약속 목록이고, 메소드는 자동으로 `public abstract`다.

대본은 이 티켓에서 영상 전체를 먼저 쓰고 길이(3분 이하)를 확인한다. 이 장면들만으로 볼 수 있는 빌드가 나와야 한다.
