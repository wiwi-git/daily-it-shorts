# 02: STEP 2 문법 + 줄여 쓰기

**What to build:** 람다식을 읽는 법과 줄여 쓰는 규칙을 보여 주는 두 장면을 대본 → 음성 → 화면까지 만든다.
- syntax: `(int s) -> { return s >= 80; }`를 매개변수 · 화살표 · 몸체 세 부분으로 색칠하고 아래에 이름표를 단다. `->`는 "화살표"라고 읽는다. `.note`: 6편 화살표 switch의 `->`와 같은 기호, 다른 뜻
- short: 한 줄씩 짧아지는 세 단계 — 타입 생략 `(s) -> { return s >= 80; }` → 괄호 생략 `s -> { return s >= 80; }` → 식 하나면 `{ return ; }` 생략 `s -> s >= 80`. 괄호 필수 규칙 칩: 매개변수 0개 `() -> …`, 2개 `(a, b) -> …`. 진행 표시는 2번째 칸
