# 04: STEP 4 forEach · removeIf · sort

**What to build:** 17편의 리스트에 람다식을 넘겨 출력·삭제·정렬하는 세 장면을 만든다. 리스트는 17편처럼 `List<…> x = new ArrayList<>();`와 `add` 줄(한 줄에 하나)을 화면에 보여 주고, 핵심 람다식 줄만 주황으로 강조한다.
- each: `names`에 민수·서준·지우를 `add` → `names.forEach(n -> System.out.println(n));`(33자를 넘으므로 화살표 뒤에서 줄바꿈) → 민수·서준·지우 세 줄
- rmif: `scores`에 85·92·78을 `add` → `scores.removeIf(s -> s < 80);` → `[85, 92]`. 람다식은 "지울 조건"이라고 말한다. 진행 표시는 4번째 칸
- sort: 새 `scores`(85·92·78) → `scores.sort((a, b) -> b - a);` → `[92, 85, 78]`. "빼기 결과로 순서를 정한다", 오름차순은 `a - b`. 매개변수가 두 개라 괄호가 필요하다는 것을 02와 연결한다. 진행 표시는 4번째 칸

색: 민수 k1·서준 k2·지우 k3, 점수 85=k1·92=k2·78=k3. 정렬 뒤에도 색은 값을 따라간다.
