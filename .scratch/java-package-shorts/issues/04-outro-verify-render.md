# 04: 정리 + 전체 검증·렌더링 + README

**What to build:** 정리 장면을 넣고 영상을 마무리한다.
- outro: 아래 6줄 목록 전체를 먼저 보여 주고, 나레이션이 각 항목을 말하는 순간 그 줄을 강조하며, 마지막에 "👍 구독 · 좋아요"를 보여 준다.
  1. `package`로 클래스를 묶고 폴더와 맞춘다
  2. 전체 이름 = 패키지 이름 + 클래스 이름
  3. `import`로 이름을 줄여 쓴다
  4. 다른 패키지에서 쓰려면 `public`
  5. `java.lang`은 import 없이
  6. 같은 이름 클래스는 하나를 전체 이름으로

그다음 영상 전체를 검증하고 렌더링한 뒤, README의 영상 목록에 행을 추가한다.
