# 01: 프로젝트 골격 + 도입·STEP 1 업캐스팅·누구의 hello?

**What to build:** 인터페이스 편(13편)과 같은 방식·템포(1.2배)로 다형성 영상 프로젝트를 만든다. 상단 바 브랜드는 "자바 입문 다형성 정리"로 하고, "다형성"을 주황으로 강조한다. 예시 클래스(`Person`·`Student`·`Teacher`)와 인터페이스(`Studyable`·`Teachable`)는 13편 것을 그대로 쓰고, 숨김 줄로 완전한 프로그램을 만든다.

도입("자바 입문 열네 번째, 다형성")과 STEP 1을 대본 → 음성 → 화면까지 만든다. STEP 1은 두 장면이다.
- up: `Person p = new Student("민수", 85);` — Student는 Person이니까 자동으로 된다. 업캐스팅이며, 화면에 처음 한 번 "(자식 → 부모 타입)"을 덧붙인다.
- call: `p.hello()`를 실행하면 `학생 민수 안녕`이 출력된다. "변수 타입: Person / 실제 객체: Student" 비교 카드로, 변수 타입이 아니라 실제 객체의 메소드가 실행된다는 것을 보여 준다.

대본은 이 티켓에서 영상 전체를 먼저 쓰고 길이(3분 이하)를 확인한다. 이 장면들만으로 볼 수 있는 빌드가 나와야 한다.
