# 02: STEP 2 배열로 한 번에·매개변수로

**What to build:** STEP 2의 두 장면을 대본 → 음성 → 화면까지 만든다. 이 영상의 핵심 장면이다.
- arr: `Person[] people`에 민수(Student)와 서준(Teacher)을 함께 담고, for-each로 `hello()`를 부른다. `학생 민수 안녕`, `서준 선생님 안녕`이 각각 다르게 출력된다. 같은 호출이 객체마다 다르게 동작하는 것이 다형성("여러 형태")이라고 설명한다. 결과 두 줄은 대상별 색(민수 k2, 서준 k3)으로 보여 준다.
- param: `static void greet(Person p)` 메소드 하나로 Student와 Teacher를 모두 처리한다. 같은 두 줄이 출력된다. 학생용·선생님용 메소드를 따로 만들 필요가 없다는 장점을 말한다.

진행 표시는 두 장면 모두 2번째 칸이다.
