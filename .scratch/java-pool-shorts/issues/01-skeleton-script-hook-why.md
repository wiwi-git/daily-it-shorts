# 01: 프로젝트 골격 + 대본 전체 + 도입·STEP 1 왜 스레드 풀인가

**What to build:** 23편(`java-sync-shorts`)과 같은 방식·템포(1.2배)로 `java-pool-shorts` 영상 프로젝트를 만든다. 음성 생성·빌드 스크립트를 복사해 장면만 바꾼다. 상단 바 브랜드는 `자바 입문 <em>스레드 풀</em> 정리`이고, 진행 표시는 why→1, submit→2, future→3, close→4(outro는 시리즈 관례대로 PROG에 넣지 않음).

이 티켓에서 **영상 전체 대본**(hook, why, submit, future, close, outro)을 먼저 쓰고 길이(목표 2분 30초 이하)를 음성으로 확인한다. 그다음 도입과 STEP 1을 대본 → 음성 → 화면까지 만든다. 나머지 장면은 제목만 있는 자리표시 화면으로 둔다.

- 공통 설정: `J.MAIN_THROWS = "Exception"`, `J.IMPORTS = ["import java.util.concurrent.*;", ""]`
- hook: "자바 입문 스물네 번째, 스레드 풀이에요. 22편에서는 작업마다 스레드를 직접 뉴 했죠. 이번엔 스레드를 미리 만들어 두고 돌려 쓰는 방법을 알아볼게요." 150px 큰 제목 "스레드 <em>풀</em>". "실무" 언급 없음
- why: 스레드도 만들고 없애는 데 시간이 든다 / 작업이 천 개면 스레드도 천 개 → 풀은 정해 둔 개수(2개)만 만들어 작업을 차례로 맡긴다. 그림: 스레드 2칸(가로 줄) 위에 작업 3개, 먼저 끝난 스레드가 세 번째 작업을 맡는 모습(빌드 스크립트 안의 짧은 HTML, 디자인 토큰 색만, 시간·숫자 없음). 실행 예제 없음

자세한 결정은 [../spec.md](../spec.md).
