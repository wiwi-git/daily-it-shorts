# 04: STEP 4 데몬 스레드

**What to build:** 시청자가 `setDaemon(true)` 한 줄로 무한 반복 스레드가 `main`과 함께 끝나는 것을 보고, 일반 스레드가 남아 있으면 `main`이 끝나도 프로그램이 끝나지 않는다는 것을 이해한다. 22편 start 장면(`main 끝` 뒤에 `서준 92`)과 24편 close 장면("고정 풀은 닫지 않으면 프로그램이 끝나지 않아요")을 나레이션 한두 문장으로 잇는다. 이전 편 화면은 다시 그리지 않는다.

- 코드: flag/interrupt 뼈대에서 `작업 끝` 출력 줄을 빼고, `while (true)`로 바꾸고, `t.start();` 앞에 `t.setDaemon(true);`(주황 강조)를 넣고, 마지막 줄을 `System.out.println("main 끝");`으로 한다
- `jmulti` 20회: 매 실행 `작업 중` 1줄 이상과 `main 끝` 한 줄, `작업 끝`은 없음, 실행이 끝남. 화면 예시는 `작업 중`×5 + `main 끝`
- `setDaemon`을 뺀 같은 프로그램은 01의 `jhang`으로 "끝나지 않음"을 검증만 하고 화면에는 그리지 않는다. 나레이션 "이 한 줄이 없으면 프로그램이 끝나지 않아요"의 근거다
- `setDaemon`은 `start()`보다 먼저 불러야 한다는 것을 코드 순서로 보여 준다(나레이션에서 말할지는 길이를 보고 정한다)

자세한 결정은 [../spec.md](../spec.md).

## Comments

- daemon: `each`는 "main 끝 정확히 1줄, 작업 중 1줄 이상, 작업 끝 없음"으로 했다. 6번째 `작업 중`이 main 끝 앞뒤 어디든 올 수 있어서 순서는 고정하지 않았다.
- 버그 수정: `jhang`이 `LAST["out"]`을 비워서 출력 상자에 "(출력 없음)"이 그려졌다 → `jhang`이 `LAST`를 건드리지 않게 공용 헬퍼를 고치고(문서 반영), `jhang` 호출도 `jmulti` 앞으로 옮겼다.
