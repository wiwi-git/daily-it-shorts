# 01: 프로젝트 골격 + 대본 전체 + 도입·STEP 1 원본은 그대로

**What to build:** 람다식 편(18편)과 같은 방식·템포(1.2배)로 "스트림" 영상 프로젝트를 만든다. 상단 바 브랜드는 18편 실제 구현과 같이 "자바 입문 스트림 정리"로 하고 "스트림"을 주황으로 강조한다. 진행 표시는 5칸이다(2-1→2, 3-1→3).

18편의 출력 대조 헬퍼와 실행 중 오류 대조 헬퍼를 그대로 가져온다. 화면에 체인 코드만 보여 주는 장면도 `scores`·`names`를 만드는 숨긴 코드와 함께 실제로 실행되게 한다.

이 티켓에서 **영상 전체 대본**을 먼저 쓰고 길이(3분 이하)를 확인한다. 그 다음 도입과 STEP 1을 대본 → 음성 → 화면까지 만든다.
- hook: "자바 입문 열아홉 번째, 스트림". 150px 큰 제목 `.stream()`(`stream` 주황), `.hook`에 `filter → map → toList`
- why: `scores`에 85·92·78을 `add`(한 줄에 하나, 이번 편에서 `add` 줄을 보여 주는 유일한 장면) → 18편 `scores.removeIf(s -> s < 80);` → `[85, 92]`(원본이 바뀜) vs 새 `scores`에서 `scores.stream().filter(s -> s >= 80).toList()` → 결과 `[85, 92]`, 원본 `scores`는 `[85, 92, 78]` 그대로. `removeIf`는 지울 조건, `filter`는 남길 조건

체인 코드는 점(`.`) 앞에서 줄을 바꿔 한 줄에 연산 하나씩 쓴다. 이 장면들만으로 볼 수 있는 빌드가 나와야 한다.
