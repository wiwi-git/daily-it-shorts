# 03: STEP 3 이어 붙이기 + sorted

**What to build:** 중간 연산을 여러 개 이어 붙이는 방법과 스트림 정렬을 보여 주는 두 장면을 만든다.
- chain: `scores.stream()` / `.filter(s -> s >= 80)` / `.map(s -> s + 5)` / `.toList()` → `[90, 97]`. `filter`·`map` 줄은 중간 연산, `toList` 줄은 최종 연산 이름표로 구분한다. `.note`: 최종 연산이 없으면 기본적으로 실행되지 않는다
- sorted: `sorted()` → `[78, 85, 92]`(작은 순), `sorted((a, b) -> b - a)` → `[92, 85, 78]`(큰 순). 18편 `sort`와 같은 람다식이고, 매개변수가 두 개라 괄호가 필요하다. 두 코드와 결과를 위아래로 비교한다. 진행 표시는 3번째 칸

색은 원래 값을 따라간다(90=k1, 97=k2, 정렬 뒤에도 85=k1·92=k2·78=k3).
