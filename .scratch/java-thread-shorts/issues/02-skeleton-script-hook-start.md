# 02: 프로젝트 골격 + 대본 전체 + 도입·STEP 1 스레드 만들기

**What to build:** 21편(`java-file-io-shorts`)과 같은 방식·템포(1.2배)로 `java-thread-shorts` 영상 프로젝트를 만든다. 음성 생성·빌드 스크립트를 복사하고, 파일 입출력 설정(`J.FILE`, 파일 내용 상자)은 걷어 낸다. 상단 바 브랜드는 `자바 입문 <em>스레드</em> 정리`이고, 진행 표시는 5칸이다(start·run-trap→1, join→2, race→3, sync→4, outro→5).

이 티켓에서 **영상 전체 대본**(hook, start, run-trap, join, race, sync, outro)을 먼저 쓰고 길이(3분 이하, 목표 2분 30초 안팎)를 음성으로 확인한다. 그다음 도입과 STEP 1을 대본 → 음성 → 화면까지 만든다.

- hook: "자바 입문 스물두 번째, 스레드". 150px 큰 제목 "스레드". 스레드 = 코드를 실행하는 흐름이고, 지금까지는 메인 스레드 하나였다
- start: `new Thread(() -> ...)`로 민수 85, 서준 92를 출력하는 두 스레드를 만들어 `start()`하고, 마지막에 `main 끝` 출력. `jmulti`로 매 실행 줄 묶음이 같은지(순서 무관) 검사하고, 화면 예시는 `민수 85 / main 끝 / 서준 92`. 나레이션은 "순서는 보장되지 않아요"와 "메인 스레드는 기다리지 않아요". `.note`: `extends Thread`로 만드는 방식도 있다. 민수 k1, 서준 k2 색
