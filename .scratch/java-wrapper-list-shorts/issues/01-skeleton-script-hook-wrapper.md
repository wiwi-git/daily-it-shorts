# 01: 프로젝트 골격 + 실행 중 예외 대조 + 대본 전체 + 도입·STEP 1 래퍼 클래스

**What to build:** 접근 제어자 편(16편)과 같은 방식·템포(1.2배)로 "래퍼 클래스와 List" 영상 프로젝트를 만든다. 상단 바 브랜드는 "래퍼 클래스와 List 정리"로 하고, "List"를 주황으로 강조한다. 진행 표시는 5칸이다(2-1→2, 3-1→3, 5-1→5).

16편의 컴파일·실행 대조 헬퍼를 가져오되, 이번 편은 패키지가 없으므로 `Main` 파일 하나만 컴파일·실행한다. 두 가지를 넓힌다.
- **실행 중 예외 대조**: 기대한 예외의 첫 줄(예: `java.lang.IndexOutOfBoundsException: Index 3 out of bounds for length 3`)이 나는지 대조한다. 기존 헬퍼는 실행 중 오류를 실패로만 처리했다
- **디버그 정보 컴파일**: NPE 문구에 변수 이름이 나오도록(`because "n" is null`, 없으면 `"<local1>"`) 디버그 정보를 넣어 컴파일한다

이 티켓에서 **영상 전체 대본**을 먼저 쓰고 길이(3분 이하)를 확인한다. 그 다음 도입과 STEP 1을 대본 → 음성 → 화면까지 만든다.
- hook: "자바 입문 열일곱 번째, 래퍼 클래스와 List". 학생이 몇 명일지 모른 채 점수를 모으고 싶다 → 문제 칩 "배열은 크기 고정", "`<int>`는 안 됨"
- wrap: 래퍼 클래스 = 기본 타입을 객체로 감싼 클래스. 대응표(`int`→`Integer`, `char`→`Character` 강조, `double`→`Double`, `boolean`→`Boolean`, 나머지는 첫 글자만 대문자). 네 래퍼 변수에 값을 담아 실제로 출력해 확인하고, 표·출력은 그 결과로 그린다

이 장면들만으로 볼 수 있는 빌드가 나와야 한다.
