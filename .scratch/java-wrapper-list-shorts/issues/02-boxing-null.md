# 02: STEP 2 오토박싱·언박싱 + null 언박싱 오류

**What to build:** 래퍼 값과 기본 타입이 자동으로 오가는 것, 그리고 `null`을 언박싱하면 실행 중 오류가 나는 것을 보여 주는 두 장면을 대본 → 음성 → 화면까지 만든다.
- box: `Integer n = 85;`(오토박싱), `int m = n + 1;`(언박싱) → `86`. 방향을 화살표 칩으로 보여 준다(`int → Integer` 오토박싱, `Integer → int` 언박싱). `Integer.parseInt("85")`로 문자열을 숫자로 바꾸고 계산 결과(예: `+ 1` → `86`)로 숫자가 됐음을 드러낸다. 래퍼는 객체라서 `null`을 담을 수 있다
- npe: `Integer n = null; int m = n;` → `NullPointerException`(`.warn`). 진행 표시는 2번째 칸
