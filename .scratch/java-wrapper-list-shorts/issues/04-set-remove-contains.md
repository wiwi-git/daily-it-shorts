# 04: STEP 4 set·remove·contains + 지우기 전·후 표

**What to build:** 리스트에서 하나를 지우면 뒤 칸이 앞으로 당겨지는 것을 표로 보여 주는 장면(edit)을 만든다.
- `[민수, 서준, 지우]`에 `add("하은")` → `[민수, 서준, 지우, 하은]`
- `remove(0)` → `[서준, 지우, 하은]`, `get(0)` → `서준`
- `contains("민수")` → `false`
- `set(0, "민수")` → `[민수, 지우, 하은]`
- 지우기 전·후 인덱스 표(0·1·2·3 열). 색은 칸이 아니라 사람을 따라간다(서준은 당겨져도 k2). 지운 민수 칸은 `out`(취소선). 하은은 색 클래스 없이 기본 글자색
