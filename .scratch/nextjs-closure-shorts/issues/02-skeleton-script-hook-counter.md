# 02: 프로젝트 골격 + 대본 전체 + 도입·STEP 1 클로저란

**What to build:** 22편(`java-thread-shorts`)과 같은 방식·템포(1.2배)로 `nextjs-closure-shorts` 영상 프로젝트를 만든다. 음성 생성·빌드 스크립트를 복사하고 스레드 전용 설정은 걷어 낸다. 상단 바 브랜드는 `Next.js <em>클로저</em> 정리`, 진행 표시 5칸(counter→1, capture→2, why→3, loop→4, snapshot·action→5, outro는 칸 없음 — 22편과 같게). `J.IMPORTS`에 `java.util.function.*`.

이 티켓에서 **영상 전체 대본**(hook, counter, capture, why, loop, snapshot, action, outro)을 먼저 쓰고 길이(3분 이하, 목표 2분 30초 안팎)를 음성으로 확인한다. 그다음 도입과 STEP 1을 대본 → 음성 → 화면까지 만든다. 나머지 장면은 자리표시 화면(제목만).

- hook: "넥스트 제이에스 첫 번째, 클로저". 150px 큰 제목 "클로저"(`<em>`). "같은 코드인데 자바스크립트는 2, 자바는 컴파일 오류?"
- counter: JS `function makeCounter() {` / `let count = 0;` / `return () => ++count;` / `}` → `c1(), c1(), c2()` 출력 `1 2 1`(01의 실행·대조 헬퍼). 클로저 정의 한 문장(MDN 기준). 함수가 끝나도 `count`가 살아 있고, `c1`·`c2`는 각자의 `count`를 가진다. `.note`: `() => x`는 자바의 `() -> x`, `let`·`const`는 변수 선언
