# 04: STEP 4 반복문 함정

**What to build:** 03의 위아래 비교 레이아웃으로 반복문에서 만든 클로저를 비교하는 장면(진행 4).

- 위 카드 자바스크립트: `for (var i ...)`로 함수 세 개를 만들어 실행 → `3,3,3`, `for (let j ...)` → `0,1,2`. `var`는 변수 하나를 함께 쓰고, `let`은 반복마다 새 변수
- 아래 카드 자바: 일반 `for`의 `i`를 람다에서 쓰면 컴파일 오류(`effectively final`), 향상된 `for` 변수는 반복마다 새 변수라 가능 → 실제 실행 출력(형식은 구현 때 결정)
- 자바는 틀릴 수 있는 쪽을 컴파일러가 막는다는 대비로 마무리
- 한 장면에 네 예제가 들어가므로 필요하면 `var`/`let`을 한 카드 안에서 위아래로, 또는 장면 안에서 순서대로 바꿔 보여 준다(배치는 구현 때 결정)

## Comments

- JS: 함수가 직접 `console.log(i)`하도록 바꿔 33자 안에 맞춤(`a.forEach(f => f());`) → `3 3 3` / `let` 버전은 같은 코드의 `var`→`let`을 실행해 `0 1 2`. 화면 코드는 `var` 버전, 칩 두 개로 비교.
- 자바: 리스트 선언은 `pre=`로 숨기고 첫 줄 주석 `// list: IntSupplier 리스트`로 표시. 일반 `for`는 `jce`, 향상된 `for`는 `jcode`(`0 1 2`).
