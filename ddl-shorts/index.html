STEP 1 · CREATE

CREATE TABLE

컬럼 이름 + 자료형을 차례로

CREATE TABLE products (
id INT PRIMARY KEY,
name VARCHAR(50) NOT NULL,
category VARCHAR(20),
price INT DEFAULT 0
);
INT = 정수VARCHAR(50) = 최대 50글자

STEP 5 · 주의

롤백 불가

MySQL DDL은 기본적으로 자동 커밋

✓ DELETE는 되돌릴 수 있음
START TRANSACTION;
DELETE FROM products;
ROLLBACK;
결과 →6행 그대로 ✓
✗ DROP은 되돌릴 수 없음
START TRANSACTION;
DROP TABLE products;
ROLLBACK;
결과 →products 테이블 없음 ⚠
⚠ DROP · TRUNCATE 전에는 백업 먼저

6DDL은 롤백 ✗
👍 구독 · 좋아요
테이블을 만들고, 바꾸고, 지우는 DDL.
크리에이트, 얼터,
드롭부터 한 번 실행하면 되돌릴
수 없는 이유까지 정리해 드립니다.
DDL은 데이터 정의어.
행에 담긴 데이터가 아니라,
테이블이라는 그릇의 구조를 다룹니다.
데이터를 넣고 고치는 DML과는
다루는 대상이 달라요.
먼저 크리에이트 테이블.
괄호 안에 컬럼 이름과
자료형을 차례로 적습니다.
인트는 정수, 바차 50은 최대 50글자까지
담는 문자열이에요.
자료형 뒤에는 제약 조건을 붙여요.
프라이머리 키는 행을 구별하는
값이라 중복도 널도 안 되고,
낫 널은 널을 막아요.
빈 문자열까지 막지는 않아요.
디폴트는 값을 안 넣으면
대신 들어가는 기본값입니다.
데스크로 구조를 확인해 보세요.
만든 뒤에 구조를 바꿀 땐 얼터 테이블.
애드 컬럼으로 재고 컬럼을 추가하면,
이미 있던 행에도 디폴트
값 0이 채워집니다.
자료형을 바꾸는 모디파이는 컬럼
정의를 통째로 다시 씁니다.
그래서 낫 널을 빼먹으면,
널을 허용하는 컬럼으로 바뀌어 버려요.
얼터 테이블 뒤에 리네임
컬럼을 쓰면 이름 변경,
드롭 컬럼을 쓰면 컬럼 삭제예요.
자주 검색하는 컬럼에는
인덱스를 만들어 둡니다.
책 뒤의 찾아보기처럼,
전체를 뒤지지 않고 원하는
행을 빨리 찾게 해 주죠.
대신 데이터를 넣고 고칠
때마다 인덱스도 함께 갱신되니,
필요한 곳에만 만드세요.
지울 때는 세 가지를 구분하세요.
드롭 테이블은 테이블 자체를,
트렁케이트는 구조는 남기고 모든 행을,
딜리트는 웨어 조건에 맞는 행만 지웁니다.
이 중 딜리트만 DML이에요.
가장 중요한 주의점.
마이에스큐엘에서 DDL은 기본적으로
실행될 때 자동으로 커밋돼요.
그래서 트랜잭션 안에서 딜리트한
행은 롤백으로 살릴 수 있지만,
드롭한 테이블은 되돌릴 수 없습니다.
드롭과 트렁케이트 전에는
꼭 백업부터 하세요.
정리하면, 크리에이트로 만들고,
제약 조건으로 지키고, 얼터로 바꾸고,
인덱스로 빠르게,
드롭은 신중하게.
DDL은 롤백이 안 된다는 것, 꼭 기억하세요.
도움이 됐다면 구독과 좋아요 부탁드립니다!
