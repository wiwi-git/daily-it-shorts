# 유튜브 업로드: 제목·설명

렌더링이 끝난 영상을 올릴 때 쓰는 제목과 설명의 형식. 꺾쇠 `< >`는 유튜브가 받지 않으므로 제목·설명 어디에도 쓰지 않는다(`List<String>`은 "String 리스트"처럼 말로 풀거나 전각 `＜＞`).

## 제목

```
자바 입문 N편: 주제 | 키워드 · 키워드 · … #shorts
```

- N은 README "영상 목록"에서 그 시리즈의 순서
- 키워드는 README 행의 괄호 안 항목에서 고른다
- 끝의 ` #shorts`까지 포함해 100자 이하

예: `자바 입문 20편: 예외 | try-catch · finally · throw · throws · 커스텀 예외 #shorts`

## 설명

```
자바 입문 N번째, 주제! 한 문장 소개.

📌 오늘 배우는 것
1. STEP별 핵심 한 줄 (코드 이름은 원문 그대로)
   ⚠️ 함정: 영상의 함정 장면 한 줄
…

💡 (있으면) 화면 메모로 나온 팁

✅ 영상 속 예제는 모두 실제로 컴파일·실행해서 확인한 결과예요 (OpenJDK 버전)

#자바 #java #자바입문 #주제태그 … #shorts
```

- 번호 목록은 영상의 STEP 순서와 같게, 나레이션에서 말한 내용만
- 첫 사례: 20편 예외, 21편 텍스트 파일 읽기·쓰기(2026-11-20)

## 업로드 뒤

README "영상 목록"에 행을 추가한다. URL은 `https://www.youtube.com/watch?v=<id>` 형식(쇼츠 공유 링크 `youtube.com/shorts/<id>`에서 id만 옮김).
