JAVA 입문 · 열두 번째

추상 메소드와
추상 클래스

abstract · new 불가
STEP 1 · 왜 필요할까

쓰이지 않는 몸체

학생도 선생님도 아닌 Person 객체

class Person {
String name;
Person(String name) { … }
void hello() {
System.out.println(
name + " 안녕");
}
}
Student · Teacher 가 모두 오버라이딩
→ 부모의 몸체는 쓰이지 않음
Person p =
new Person("서준");
p.hello();
실행 결과 (어중간한 객체)
서준 안녕
STEP 1 · 추상 메소드

몸체 없이 ;

abstract = 자식이 꼭 완성하라

일반 메소드{ … }몸체 있음
추상 메소드;몸체 없음
abstract void hello();
중괄호 { } 대신 ; 로 끝난다
STEP 2 · 추상 클래스

클래스에도 abstract

추상 메소드가 있으면 클래스도 abstract

class Person {
String name;
abstract void hello();
}
컴파일 오류
Person is not abstract and does not override abstract method hello() in Person
abstract class Person {
String name;
abstract void hello();
}
STEP 2-1 · new 불가

객체를 만들 수 없다

추상 클래스는 new 불가

Person p =
new Person("서준");
컴파일 오류
Person is abstract; cannot be instantiated
어중간한 Person 객체를 막아 준다
STEP 3 · 자식이 완성

오버라이딩으로 완성

자식 클래스가 hello() 를 완성

class Student extends Person {
@Override void hello() { … }
}
class Teacher extends Person {
@Override void hello() { … }
}
s.hello();
t.hello();
실행 결과
학생 민수 안녕
서준 선생님 안녕
STEP 3-1 · 빠뜨리면?

hello() 가 없으면 오류

해결: 오버라이딩 또는 자식도 abstract

class Teacher extends Person {
// hello() 없음
}
컴파일 오류
Teacher is not abstract and does not override abstract method hello() in Person
abstract class Teacher
extends Person { … }
new Teacher("서준");
컴파일 오류
Teacher is abstract; cannot be instantiated
STEP 4 · 추상 클래스의 구성

필드 · 생성자도 OK

일반 메소드도 함께 가질 수 있다

abstract class Person {
String name; // 필드
Person(String name) { // 생성자
this.name = name;
}
abstract void hello();
void bye() { … } // 일반
}
class Student extends Person {
Student(…) {
super(name);
…
}
}
s.bye() 실행 결과 (물려받은 일반 메소드)
민수 잘 가
STEP 5 · 주의

알아 둘 두 가지

abstract 와 final 은 반대

추상 메소드가 없어도 추상 클래스 가능
abstract class Person {
String name;
}
abstract final class Person {
abstract void hello();
}
컴파일 오류
illegal combination of modifiers: abstract and final
abstract = 물려받아 완성
final = 물려받지 마
정리

abstract 6가지

1추상 메소드 = 몸체 없이 ;
2추상 메소드 있으면 abstract
3추상 클래스 = new 불가
4자식은 꼭 오버라이딩
5아니면 자식도 abstract
6필드·생성자·일반 메소드 OK
