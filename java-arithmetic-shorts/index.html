STEP 3 · 0으로 나누기

0으로 나누면?

정수는 실행 에러, 실수는 Infinity

✓ 컴파일은 성공 → ✗ 실행 중 에러 (% 도 같음)
int n = 0;
System.out.println(17 / n);
실행 오류
Exception in thread "main"
java.lang.ArithmeticException:
/ by zero
실수 ÷ 0
System.out.println(17.0 / n);
실행 결과
Infinity
STEP 4 · 계산 순서

계산 순서

* / % 가 + - 보다 먼저

int a = 3 * 5 + 2; // 17
int b = 3 * (5 + 2); // 21
int c = 17 / 5 * 2; // 6
우선순위
( )>* / %>+ -
순위가 같으면 왼쪽부터
17 / 5 * 2 → 3 * 2 → 6
헷갈릴 땐 괄호가 가장 확실
STEP 5 · 복합 대입

복합 대입 연산자

계산하고 같은 변수에 다시 넣기

System.out.println(candy);

STEP 5-1 · 증감 연산자

++ 와 --

1씩 늘리고 줄이기

x++ = x = x + 1
x-- = x = x - 1
후위 x++ : 대입 먼저 → 증가
int x = 5;
int y = x++; // y=5, x=6
전위 ++x : 증가 먼저 → 대입
int x = 5;
int y = ++x; // y=6, x=6
혼자 한 줄 x++; ++x; → 차이 없음
정리

산술연산자 핵심 7가지

1+ - * / % 다섯 가지
217 / 5 → 몫 3
317 % 5 → 나머지 2
417 / 5.0 → 3.4
517 / 0 → 실행 에러
6* / % 가 + - 보다 먼저
7+= · ++ 줄여 쓰기
