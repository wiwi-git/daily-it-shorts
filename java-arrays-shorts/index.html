STEP 2 · new로 만들기

new 연산자

👍 구독 · 좋아요
자바 입문 세 번째, 배열!
배열의 개념부터 뉴 연산자, 값 교환, 인덱스 에러,
다차원 배열까지 정리해 드립니다.
배열은 같은 타입의 값 여러 개를,
하나의 이름으로 묶어 저장하는 공간이에요.
학생 세 명의 점수를 변수
세 개에 따로 담는 대신,
스코어즈라는 배열 하나에 담을 수 있어요.
각 칸은 인덱스라는 번호로 구분하는데,
인덱스는 영부터 시작합니다.
그래서 첫 번째 칸은 스코어즈 영,
값은 구십이에요.
배열은 뉴 연산자로 만들어요.
인트 배열 스코어즈 이퀄 뉴 인트 삼은,
정수 세 칸짜리 배열을 만들라는 뜻이에요.
한 번 정한 크기는 나중에 바꿀 수 없어요.
그리고 값을 넣지 않은
칸에는 기본값이 들어가요.
인트는 영, 더블은 영 점 영, 불리언은 펄스,
스트링은 널입니다.
값을 넣을 때는 스코어즈 영 이퀄 구십처럼,
대괄호 안에 인덱스를 써서 대입해요.
꺼낼 때도 똑같이 스코어즈
영이라고 쓰면 됩니다.
만들면서 바로 값을 넣으려면
중괄호로 초기화해요.
이때는 뉴를 쓰지 않아도,
값의 개수만큼 크기가 정해져요.
배열의 크기는 점 렝스로 알 수 있고,
여기서는 삼이 나옵니다.
두 칸의 값을 서로 바꿀 때는
임시 변수 템프가 필요해요.
먼저 스코어즈 영의
구십을 템프에 옮겨 두고,
스코어즈 영에 스코어즈
일의 칠십오를 넣은 다음,
템프의 구십을 스코어즈 일에 넣어요.
그러면 칠십오, 구십,
팔십팔이 됩니다.
템프 없이 바로 덮어쓰면,
구십이 사라져서 둘 다 칠십오가 돼요.
인덱스는 영부터 렝스 빼기
일까지만 쓸 수 있어요.
길이가 삼인 배열의 마지막 인덱스는 이예요.
스코어즈 삼처럼 크기를 넘는 인덱스를 쓰면,
컴파일은 되지만 실행하는
순간 에러가 납니다.
어레이 인덱스 아웃 오브 바운즈 익셉션,
인덱스 삼은 길이 삼의
범위를 벗어났다는 뜻이에요.
그래서 마지막 칸은 렝스 빼기
일로 꺼내는 게 안전해요.
배열 안에 배열을 담으면 다차원 배열이에요.
대괄호를 두 번 써서 뉴 인트 이, 삼이라고 하면,
이 행 삼 열짜리 표가 만들어져요.
시츠 일 이에 칠을 넣으면,
일 번 행의 이 번 열,
즉 두 번째 줄 세 번째 칸에 들어가요.
시츠 점 렝스는 행의 개수인 이,
시츠 영 점 렝스는 한 행의
칸 수인 삼이에요.
정리하면, 배열은 같은 타입 값의 묶음,
뉴로 크기를 정해 만들고,
인덱스는 영부터, 교환은 템프로,
렝스 이상의 인덱스는 실행 에러,
다차원은 대괄호 두 번.
반복문 편에서 배열과 함께 다시 만나요.
도움이 됐다면 구독과 좋아요 부탁드립니다!
