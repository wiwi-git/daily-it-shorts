STEP 5 · 없는 필드

선언 안 한 필드는 오류

필드는 클래스에 먼저 선언

s1.age = 20;
컴파일 오류
cannot find symbol
class Student 에 없는 이름
class Student {
String name; // 이름
int score; // 점수
}
age 를 쓰려면 int age; 를 먼저 선언
정리

클래스 핵심 7가지

1클래스 = 틀 · 객체 = 실체
2new 로 객체 생성
3s1.name 점으로 접근
4기본값 0 · false · null
5객체마다 필드는 따로
6s3 = s1 → 같은 객체
7없는 필드 → 컴파일 오류

중괄호 안에 선언한 변수를 필드라고 해요.
이름과 점수, 두 필드를 가졌죠.
메인과 같은 파일에 써도 되는데,
퍼블릭 클래스는 파일 이름과
같은 하나만 둘 수 있어요.
클래스는 틀일 뿐이라,
쓰려면 객체를 만들어야 해요.
뉴 스튜던트로 객체를 만들고,
스튜던트 타입 변수 에스 원에 담아요.
정확히는 에스 원이 그
객체를 가리키는 거예요.
이렇게 클래스로 만든 객체를
인스턴스라고도 불러요.
필드는 변수 이름 뒤에 점을 찍어서 써요.
에스 원 닷 네임에 민수,
에스 원 닷 스코어에 팔십오를 넣고,
똑같이 점으로 꺼내 출력하면,
민수와 팔십오가 나와요.
값을 넣지 않은 필드는 어떨까요?
필드에는 기본값이 자동으로 들어가요.
인트는 영, 더블은 영 점 영, 불리언은 폴스,

그래서 새 객체의 필드를 바로

틀 하나로 붕어빵을 여러 개 찍을 수 있죠.
에스 투를 하나 더 만들어 지영,
구십이를 넣어도,
에스 원은 그대로 민수, 팔십오예요.
필드는 객체마다 따로 있어요.

에스 쓰리에 에스 원을 대입해도
객체가 복사되지 않아요.

그리고 클래스에 선언하지 않은

필드는 클래스 안에 먼저 선언해야 해요.
