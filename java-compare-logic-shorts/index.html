STEP 1 · 비교 연산자

결과는 true / false

두 값을 비교해 boolean으로

==같다
!=다르다
>크다
<작다
>=크거나 같다
<=작거나 같다

false
STEP 1-1 · 자주 하는 실수

= 와 ==

= 하나는 대입 · == 두 개가 비교

score = 85 대입
score == 85 비교
문자열은 equals() — == 는 같은 객체인지 비교
String a = "java";
String b = new String("java");
System.out.println(a == b);
System.out.println(a.equals(b));
실행 결과
false
true
STEP 2 · 논리 연산자

&& · || · !

조건 여러 개를 묶기

진리표
ABA && BA || B!A

score = 85, age = 20 일 때
boolean p = score >= 80
&& age >= 20; // true
boolean q = score >= 90
|| age >= 18; // true
STEP 2-1 · 단락 평가

앞에서 결정되면 끝

&& 앞이 false · || 앞이 true → 뒤는 건너뜀

int x = 0;
boolean ok = x != 0
&& 10 / x > 1;
실행 결과
false
✗ 순서를 바꾸면 → 0으로 나누기
boolean ok = 10 / x > 1
&& x != 0;
실행 오류
Exception in thread "main"
java.lang.ArithmeticException:
/ by zero
STEP 3 · 범위 검사

0 ≤ score ≤ 100 ?

수학처럼 쓰면 컴파일 에러

✗ 수학식 그대로
boolean ok = 0 <= score <= 100;
컴파일 오류
bad operand types for binary operator '<='
0 <= score 가 먼저 true
→ true <= 100 은 비교 불가
✓ && 로 나눠서
boolean ok = score >= 0
&& score <= 100;
STEP 4 · 우선순위

연산자 우선순위

헷갈릴 땐 괄호가 가장 확실

! ++ 단항>* / + - 산술>< >= 비교>== != >&& >|| >= 대입
score = 85, age = 20 일 때
boolean r = ++age > 20
&& score + 5 >= 90;
1단항++age→ 21
2산술score + 5→ 90
3비교21 > 20 · 90 >= 90→ true, true
4논리true && true→ true
5대입r = true
정리

비교·논리 핵심 7가지

1비교 결과 → true / false
2= 대입 · == 비교
3문자열은 equals()
4&& · || · !
5단락 평가: 앞에서 결정
6범위는 && 로 나눠서
7산술 > 비교 > 논리 > 대입
👍 구독 · 좋아요
자바 입문 다섯 번째,
비교와 논리 연산자!
참과 거짓을 만드는 연산자와,
여러 연산자가 섞일 때의
우선순위까지 정리해 드립니다.
비교 연산자는 두 값을 비교해서, 맞으면 트루,
틀리면 폴스를 돌려줘요.
같다, 다르다, 크다, 작다, 크거나 같다, 작거나 같다,
이렇게 여섯 가지예요.
스코어가 팔십오일 때,
스코어 크거나 같다 팔십은 트루,
스코어 같다 백은 폴스예요.
결과는 불리언 변수에 담을 수 있어요.
자주 하는 실수 두 가지.
이퀄 하나는 대입이고,
두 개를 붙여야 비교예요.
그리고 문자열이 같은지는
이퀄스 메서드로 비교해요.
이퀄 두 개는 내용이 아니라
같은 객체인지를 보기 때문에,
글자가 같아도 폴스가 나올 수 있거든요.
논리 연산자는 조건 여러 개를 묶어요.
앤드는 둘 다 참일 때만 참,
오어는 하나라도 참이면 참,
낫은 참과 거짓을 뒤집어요.
스코어가 팔십 이상이고
에이지가 이십 이상이면 트루,
스코어가 구십 이상이거나 에이지가
십팔 이상이어도 트루예요.
앤드와 오어는 단락 평가를 해요.
앤드는 앞이 폴스면 결과가 이미 폴스라서,
뒤는 계산하지 않아요.
그래서 엑스가 영일 때,
엑스가 영이 아니고 십 나누기 엑스가
일보다 크다는 에러 없이 폴스예요.
순서를 바꾸면 영으로 나누기 에러가 나요.
오어는 앞이 트루면 뒤를 건너뛰어요.
점수가 영에서 백 사이인지 볼 때,
수학처럼 영 작거나 같다 스코어 작거나
같다 백으로 쓰면 컴파일 에러예요.
앞의 비교가 먼저 불리언이 되고,
불리언과 숫자는 비교할 수 없거든요.
앤드로 나눠서, 스코어가 영 이상,
그리고 백 이하로 써야 해요.
연산자가 섞이면 우선순위대로 계산해요.
낫이나 플러스 플러스 같은
단항 연산자가 가장 먼저, 다음은 산술, 비교,
같다 다르다, 앤드, 오어 순서고,
대입은 맨 마지막이에요.
예를 들어 플러스 플러스
에이지가 이십보다 크고,
스코어 더하기 오가 구십 이상인지 볼게요.
먼저 단항 연산으로 에이지가 이십일,
스코어 더하기 오는 구십,
비교하면 둘 다 트루,
앤드로 묶어 트루,
마지막에 알에 대입돼요.
헷갈릴 땐 괄호가 가장 확실해요.
정리하면, 비교 연산자의 결과는 트루 아니면 폴스,
이퀄 하나는 대입이고 두 개가 비교,
문자열은 이퀄스,
논리 연산자 앤드, 오어, 낫,
앞에서 결정되면 뒤는 건너뛰는 단락 평가,
범위는 앤드로 나눠 쓰기, 그리고 산술, 비교, 논리,
대입 순서의 우선순위.
구독과 좋아요 부탁드립니다!
