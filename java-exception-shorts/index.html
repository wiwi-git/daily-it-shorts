STEP 5 · 커스텀 예외

예외 클래스 만들기

커스텀 예외 (직접 만든 예외 클래스)

class ScoreException
extends Exception {
ScoreException(
String message) {
super(message);
}
}
static void checkScore(int s)
throws ScoreException {
if (s < 0 || s > 100)
throw new ScoreException(
"점수 오류: " + s);
}
try {
checkScore(120);
} catch (ScoreException e) {
System.out.println(
e.getMessage());
}
실행 결과
점수 오류: 120
super(message)
→ getMessage()
