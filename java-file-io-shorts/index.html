STEP 1-1 · 이어쓰기

뒤에 덧붙이기

FileWriter에 true → 이어쓰기

try (BufferedWriter w =
new BufferedWriter(
new FileWriter(
"scores.txt", true))) {
w.write("지우,78");
w.newLine();
}
📄 scores.txt · true
민수,85
서준,92
지우,78
📄 scores.txt · true 없음
지우,78
함정! true를 빼면 덮어쓰기
기존 두 줄이 지워지고 지우만 남음 · 덮어쓰기가 기본

STEP 3 · 읽어서 계산

합계 구하기

split으로 나누고 parseInt로 숫자로

int sum = 0;
try (BufferedReader r =
new BufferedReader(
new FileReader(
"scores.txt"))) {
String line;
while ((line = r.readLine())
!= null) {
String[] p = line.split(",");
sum += Integer.parseInt(
p[1]);
}
}
System.out.println(sum);
"민수,85"
.split(",")
→ [민수, 85]
실행 결과
255
STEP 4 · 파일 예외

없는 파일 읽기

IOException으로 잡기

try (BufferedReader r =
new BufferedReader(
new FileReader(
"score.txt"))) {
System.out.println(
r.readLine());
} catch (IOException e) {
System.out.println(e);
}
실행 결과
java.io.FileNotFoundException: score.txt (No such file or directory)
IOException = 체크 예외 (처리 강제)
try-catch 또는 throws 없으면 → 컴파일 오류
STEP 5 · 짧게 쓰기

Files 한 줄

writeString으로 쓰고 readAllLines로 읽기

public static void main(
String[] args)
throws IOException {
Path p = Path.of("scores.txt");
Files.writeString(p,
"민수,85\n서준,92\n지우,78\n");
System.out.println(
Files.readAllLines(p));
}
📄 scores.txt
민수,85
서준,92
지우,78
readAllLines
→ 모든 줄을 List로
실행 결과
[민수,85, 서준,92, 지우,78]
