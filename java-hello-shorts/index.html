👍 구독 · 좋아요
프로그래밍의 첫걸음, 헬로 월드!
자바 프로그램의 기본 형태부터 문자열 출력, 줄바꿈,
그리고 프린트와 프린트엘엔의
차이까지 짧게 정리해 드립니다.
먼저 전체 모습부터 볼게요.
이 다섯 줄이 화면에 헬로 월드를 출력하는
가장 기본적인 자바 프로그램입니다.
클래스가 메인 메서드를 감싸고,
메인 메서드 안에 출력 문장이 들어 있어요.
자바 코드는 클래스 안에 작성합니다.
퍼블릭 클래스 메인이라고 썼다면,
파일 이름도 클래스 이름과 똑같이
메인 닷 자바로 저장해야 해요.
다르면 컴파일 오류가 납니다.
저장한 파일은 자바씨로 컴파일하고,
자바 명령으로 실행해요.
클래스 안의 퍼블릭 스태틱 보이드 메인은
프로그램의 시작점인 메인 메서드예요.
자바는 이 메서드부터 실행을 시작합니다.
처음에는 이 줄을 통째로 외워 두세요.
중괄호는 블록의 시작과 끝을 묶고,
문장 끝에는 꼭 세미콜론을 붙입니다.
출력할 글자, 즉 문자열은 큰따옴표로 감쌉니다.
따옴표 안의 내용이 적힌 그대로 출력돼요.
작은따옴표로 감싸거나 따옴표를
빼먹으면 컴파일 오류가 납니다.
작은따옴표는 문자 하나를
나타낼 때 쓰거든요.
시스템 닷 아웃 닷 프린트엘엔은
괄호 안의 값을 출력하고,
끝에서 줄을 바꿉니다.
시스템 아웃은 표준 출력,
보통은 콘솔 화면이에요.
그래서 두 번 쓰면 두 줄로 출력되죠.
자바는 대소문자를 구분하니,
시스템의 에스는 꼭 대문자로 쓰세요.
문자열 안에 백슬래시 엔을 넣으면,
그 자리에서 줄이 바뀝니다.
하이 백슬래시 엔 자바를 출력하면,
문장은 하나지만 두 줄로 나와요.
이렇게 백슬래시로 시작하는 특수
문자를 이스케이프 문자라고 하고,
탭은 백슬래시 티,
큰따옴표는 백슬래시 큰따옴표로 씁니다.
마지막으로 프린트와 프린트엘엔 비교입니다.
프린트는 출력만 하고 줄을 바꾸지 않아요.
그래서 에이와 비를 프린트로,
씨를 프린트엘엔으로 출력하면
에이비씨가 한 줄에 붙고,
다음 디는 새 줄에서 시작합니다.
프린트에 백슬래시 엔을 붙이면,
프린트엘엔처럼 줄을 바꿀 수 있어요.
정리하면, 클래스와 메인 메서드,
문자열은 큰따옴표,
출력은 시스템 아웃 프린트엘엔,
줄바꿈은 백슬래시 엔,
그리고 프린트와 프린트엘엔의 차이.
이것만 알면 자바 첫 프로그램 완성!
도움이 됐다면 구독과 좋아요 부탁드립니다!
