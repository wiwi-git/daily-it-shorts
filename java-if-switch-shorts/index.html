JAVA 입문 · 여섯 번째

조건문
if · switch

조건에 따라 다른 실행
STEP 1 · if문

if문

조건이 true일 때만 { } 안을 실행

int score = 85;
if (score >= 60) {
System.out.println("합격");
}
실행 결과
합격
한 줄이면 { } 생략도 가능
if (score >= 60)
System.out.println("합격");
실수를 막으려면 항상 { }
STEP 2 · if-else

if-else

둘 중 하나만 실행

if (score >= 90) {
System.out.println("장학금");
} else {
System.out.println("다음 기회");
}
실행 결과
다음 기회
score = 85 → 90 이상 아님
→ else 쪽 실행
STEP 3 · else if

else if

위에서부터 첫 번째 true 하나만

if (score >= 90) {
System.out.println("A");
} else if (score >= 80) {
System.out.println("B");
} else if (score >= 70) {
System.out.println("C");
} else {
System.out.println("F");
}
실행 결과
B
그래서 큰 점수부터 차례로 검사
STEP 3-1 · 삼항 연산자

? :

간단한 if-else를 한 줄로

조건?참일 때 값:거짓일 때 값
String r = score >= 60
? "합격" : "불합격";
System.out.println(r);
실행 결과
합격
같은 if-else
String r;
if (score >= 60) {
r = "합격";
} else {
r = "불합격";
}
STEP 4 · switch문

switch문

값 하나를 case와 맞춰 보기

switch (day) {
case 3:
System.out.println("수요일");
break;
case 4:
System.out.println("목요일");
break;
default:
System.out.println("그 외");
}
day = 3 일 때
break 있음
수요일
✗ case 3의 break 빠뜨리면
수요일
목요일
STEP 5 · 화살표 switch

case 3 ->

자바 14부터 · break 없이

String name = switch (day) {
case 3 -> "수요일";
case 4 -> "목요일";
default -> "그 외";
};
name 출력
수요일
String type = switch (day) {
case 6, 7 -> "주말"; // 묶기
default -> "평일";
};
type 출력
평일

if vs switch

정리

조건문 핵심 7가지

1if → true일 때 실행
2else → false일 때
3else if → 첫 true 하나만
4조건 ? 참 : 거짓
5switch → 값 맞추기
6case마다 break
7case 3 -> (자바 14+)

자바 입문 여섯 번째, 조건문!
조건에 따라 다른 코드를 실행하는
이프문과 스위치문을 정리해 드립니다.
이프문은 괄호 안의 조건이 트루일
때만 중괄호 안을 실행해요.
스코어가 팔십오면,
스코어 육십 이상이
트루라서 합격이 출력돼요.
조건에는 비교와 논리 연산자를 그대로 써요.
실행할 문장이 한 줄이면
중괄호를 생략할 수 있지만,
실수를 막으려면 항상 쓰는 게 좋아요.
조건이 폴스일 때 실행할
코드는 엘스 뒤에 써요.
이프와 엘스 중 딱 하나만 실행돼요.
스코어 구십 이상이면 장학금인데,
팔십오는 아니니까 엘스 쪽의
다음 기회에가 출력돼요.
조건이 여러 개면 엘스 이프로 이어 써요.
위에서부터 차례로 검사하다가,
처음 트루가 나온 블록 하나만
실행하고 나머지는 건너뛰어요.
팔십오는 구십 이상이 아니고,
팔십 이상이라서 비 학점이에요.
그래서 큰 점수부터 차례로 검사해야 해요.
값 하나를 고르는 간단한 이프 엘스는
삼항 연산자로 줄일 수 있어요.
조건, 물음표, 참일 때 값, 콜론,
거짓일 때 값 순서예요.
스코어 육십 이상이면 합격, 아니면 불합격.
팔십오라서 합격이에요.
스위치문은 변수 값 하나를
여러 케이스와 맞춰 봐요.
데이가 삼이면 케이스 삼의 수요일로 가고,
맞는 케이스가 없으면 디폴트가 실행돼요.
각 케이스 끝의 브레이크가 중요해요.
빠뜨리면 다음 케이스까지 이어서 실행돼서,
수요일 다음에 목요일까지 출력돼요.
자바 십사부터는 화살표
스위치를 쓸 수 있어요.
케이스 삼 화살표 수요일처럼 쓰면,
브레이크가 없어도 다음
케이스로 넘어가지 않아요.
케이스 육, 칠처럼 값을 묶을 수 있고,
결과를 바로 변수에 담을 수도 있어요.
데이가 삼이라 평일이에요.
그럼 언제 무엇을 쓸까요?
점수 구간처럼 범위나 복잡한 조건은 이프문,
요일 번호처럼 값 하나와 정확히 맞춰
볼 때는 스위치문이 읽기 쉬워요.
정리하면, 이프는 조건이 트루일 때 실행,
엘스는 폴스일 때,
엘스 이프는 첫 번째 트루 하나만,
간단한 선택은 삼항 연산자,
스위치는 값 맞추기,
케이스마다 브레이크,
그리고 자바 십사부터는 화살표 스위치.
구독과 좋아요 부탁드립니다!
