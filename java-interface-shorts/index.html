부모는 하나만

Teacher

→ 부모 클래스 둘은 불가
능력은 인터페이스 로 약속한다
STEP 1 · 선언

약속 목록

interface = 갖춰야 할 메소드

interface Studyable {
void study();
}
몸체 없는 메소드 = 자동으로
public abstract
STEP 2 · implements

implements 로 구현

extends 다음에 implements

class Student extends Person
implements Studyable {
@Override
public void study() {
System.out.println(
name + " 공부 중");
}
}
s.study() 실행 결과
민수 공부 중
STEP 2-1 · 빠뜨리면?

study() 가 없으면 오류

일반 클래스는 꼭 갖춰야 한다

class Student extends Person
implements Studyable {
// study() 없음
}
컴파일 오류
Student is not abstract and does not override abstract method study() in Studyable
추상 메소드와 같은 강제
STEP 2-2 · public 필수

public 을 빼면 오류

가장 흔한 실수

class Student extends Person
implements Studyable {
@Override
void study() { … }
}
컴파일 오류
study() in Student cannot implement study() in Studyable
attempting to assign weaker access privileges; was public
인터페이스의 추상 메소드 = 원래 public
→ 더 좁힐 수 없다
STEP 3 · 여러 개 구현

쉼표로 여러 개

Teachable + Studyable

class Teacher extends Person
implements Teachable,
Studyable {
public void teach() { … }
public void study() { … }
}
t.teach() · t.study() 실행 결과
서준 수업 중
서준 공부 중
extends 하나implements 여러 개
STEP 4 · 상수와 new

필드는 상수

자동으로 public static final

interface Studyable {
int MAX_HOURS = 8;
}
Studyable.MAX_HOURS →8
Studyable.MAX_HOURS = 9;
컴파일 오류
cannot assign a value to static final variable MAX_HOURS
new Studyable();
컴파일 오류
Studyable is abstract; cannot be instantiated
STEP 5 · default 메소드

몸체 있는 메소드

default = 구현 안 해도 OK

interface Studyable {
void study();
default void rest() {
System.out.println(
"쉬는 중");
}
}
class Student extends Person
implements Studyable {
// rest() 구현 없음
}
s.rest() 실행 결과
쉬는 중

무엇이 다를까
