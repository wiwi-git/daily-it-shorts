STEP 1 · for문

for문의 세 부분

세미콜론 ; 으로 나뉜 세 부분

for (초기식; 조건식; 증감식)
부분코드언제
초기식int i = 1처음 한 번
조건식i <= 5매번 검사
증감식i++한 바퀴 끝마다
for (int i = 1; i <= 5; i++) {
System.out.print(i + " ");
}
실행 결과
1 2 3 4 5
i = 6 → 조건 false → 끝
STEP 2 · 합계 구하기

1부터 10까지 더하기

sum += i 로 누적

int sum = 0;
for (int i = 1; i <= 10; i++) {
sum += i; // sum = sum + i
}
System.out.println(sum);
실행 결과
55
sum 이 바뀌는 과정
1 → 3 → 6 → 10 → … → 55
STEP 2-1 · 배열과 for문

배열 순회

i < arr.length 까지

int[] arr = {85, 92, 78};
for (int i = 0; i < arr.length;
i++) {
System.out.print(arr[i] + " ");
}
실행 결과
85 92 78
향상된 for: 값만 꺼낼 때
for (int x : arr) {
System.out.print(x + " ");
}
실행 결과
85 92 78
STEP 3 · while문

while문

조건이 true인 동안 반복

int n = 1;
while (n <= 100) {
n *= 2;
}
System.out.println(n);
실행 결과
128
n 이 바뀌는 과정
1 → 2 → 4 → 8 → 16 → 32 → 64 → 128
몇 번 돌지 미리 모를 때
STEP 3-1 · do-while문

do-while문

조건은 뒤에서 · 최소 한 번 실행

int n = 200;
do {
System.out.println(n);
} while (n <= 100);
실행 결과
200
같은 조건의 while → 0번
while (n <= 100) {
System.out.println(n);
}
실행 결과
(출력 없음)

STEP 4-1 · 무한 루프

무한 루프 주의

조건이 계속 true면 끝나지 않음

✗ n 이 바뀌지 않음
int n = 1;
while (n <= 100) {
System.out.println(n);
}
1 1 1 1 1 … 영원히 반복
✓ 조건에 쓰인 변수를 바꾸기
while (n <= 100) {
System.out.println(n);
n *= 2; // ← 꼭 필요
}
정리

반복문 핵심 7가지

1for (초기식; 조건식; 증감식)
2sum += i 로 누적
3i < arr.length 까지
4while: 조건만으로 반복
5do-while: 최소 한 번
6break 탈출 · continue 건너뛰기

매번 검사하는 조건식,

아이를 일부터 오까지 하나씩 늘리면,
일부터 오까지 다섯 번 출력돼요.
아이가 육이 되면 조건이 폴스라서 끝나요.
반복문으로 일부터 십까지 더해 볼게요.
섬을 영으로 두고,
매 바퀴 섬 플러스 이퀄 아이.
산술연산자 편의 복합 대입이죠.
반복이 끝나면 섬은 오십오예요.
배열과 함께 쓰면 더 편해요.
아이를 영부터 시작해서,
배열 길이를 뜻하는 닷
렝스보다 작을 때까지 돌면,
모든 칸을 차례로 꺼낼 수 있어요.
값만 필요하면 콜론을 쓰는 향상된
포문으로 더 짧게 쓸 수 있어요.
와일문은 조건만 있어요.
조건이 트루인 동안 계속 반복하죠.
몇 번 돌지 미리 모를 때 좋아요.
엔을 일로 두고 두 배씩 늘리면,
백을 처음 넘는 값은 백이십팔이에요.
두 와일문은 조건을 뒤에서 검사해요.
그래서 조건이 처음부터 폴스여도,
본문이 최소 한 번은 실행돼요.
엔이 이백이어도 한 번 출력되죠.
같은 조건의 와일문은
한 번도 실행되지 않아요.
반복을 중간에 제어할 땐
브레이크와 컨티뉴를 써요.
브레이크는 반복문을 바로 빠져나오고,
컨티뉴는 이번 바퀴의 나머지만
건너뛰고 다음 바퀴로 가요.
일부터 십까지 돌면서
홀수는 컨티뉴로 건너뛰고,
육보다 크면 브레이크로 멈추면, 이, 사, 육만 출력돼요.
주의할 점은 무한 루프예요.
와일문에서 증감을 빠뜨리면 조건이 계속
트루라서 프로그램이 끝나지 않아요.
