STEP 1 · 메소드

메소드 = 객체의 동작

필드 이름을 그대로 사용

class Student {
...
void hello() {
System.out.println(
name + " 안녕");
}
}
void 반환 타입hello 이름( ) 괄호{ } 할 일
Student s1 = new Student();
s1.name = "민수";
s1.score = 85;
s1.hello();
실행 결과
민수 안녕
STEP 2 · 매개변수

값을 넘겨받기

받는 변수 = 매개변수, 넘기는 값 = 인자

class Student {
...
void addScore(int n) {
score += n;
}
}
s1.addScore(5);
System.out.println(s1.score);
int n매개변수
5인자
실행 결과 (85 + 5)
90
STEP 3 · return

결과 돌려주기

void 자리에 돌려줄 타입

class Student {
...
boolean isPass() {
return score >= 60;
}
}
System.out.println(s1.isPass());
실행 결과 (85 ≥ 60)
true
void돌려주는 값 없음
booleantrue / false
STEP 4 · 생성자

new 할 때 값 넣기

클래스와 이름이 같고, 반환 타입 없음

class Student {
...
Student(String name,
int score) {
this.name = name;
this.score = score;
}
}
Student s1 =
new Student("민수", 85);
s1.name, s1.score 출력
민수 85
STEP 4-1 · this

this = 객체 자기 자신

필드와 매개변수 이름이 같을 때 구분

this.name이 객체의 필드
name넘겨받은 매개변수
this 를 빼면?
class Student {
...
Student(String name,
int score) {
name = name; // this 없음
score = score;
}
}
new Student("민수", 85) 뒤 s1.name, s1.score
null 0
필드는 그대로 null · 0
STEP 5 · 기본 생성자

기본 생성자란?

매개변수 없고, 중괄호 안이 비어 있는 생성자

생성자가 하나도 없으면
class Student {
String name; // 이름
int score; // 점수
// Student() {}
// ↑ 자바가 자동으로 추가
}
Student s = new Student();
그래서 지난 시간 new Student() 가 됐던 것
STEP 5-1 · 주의

빈 괄호가 안 될 때

생성자를 만들면 기본 생성자는 안 생김

Student s = new Student();
컴파일 오류
constructor Student in class Student cannot be applied to given types;
해결: 빈 괄호 생성자 추가 = 오버로딩
class Student {
...
Student() {} // 빈 괄호용
Student(String name,
int score) { … }
}
정리

메소드 · 생성자 8가지

1메소드 = 클래스 안의 동작
2s1.hello() 점으로 호출
3매개변수로 값 받기
4return 으로 결과 돌려주기
5생성자 = 클래스 이름, 반환 타입 X
6this = 객체 자기 자신
7기본 생성자 = 자동 추가
8생성자 만들면 기본 생성자 X

자바 입문 아홉 번째,
메소드와 생성자!
객체에 동작을 넣는 메소드와,
객체를 만들 때 값을 바로 넣는
생성자까지 정리해 드립니다.
지난 시간의 스튜던트 클래스에
동작을 넣어 볼게요.
클래스 안에 정의한 동작을 메소드라고 해요.
보이드 헬로, 괄호,
중괄호 순서로 쓰고,
중괄호 안에 할 일을 적어요.
메소드 안에서는 필드 이름을
그대로 쓸 수 있어요.
호출은 필드처럼 점을 찍어서,
에스 원 닷 헬로, 괄호.
그러면 민수 안녕이 출력돼요.
메소드에 값을 넘길 수도 있어요.
애드 스코어의 괄호 안에
선언한 인트 엔을 매개변수,
호출할 때 넣는 값 오를 인자라고 해요.
에스 원 닷 애드 스코어 오를 호출하면,
엔에 오가 들어가서 점수가
팔십오에서 구십이 돼요.
메소드가 결과를 돌려줄 수도 있어요.
보이드 자리에 돌려줄 값의 타입을 쓰고,
리턴으로 값을 돌려줘요.
이즈 패스는 점수가
육십 이상이면 트루를 돌려줘요.
호출한 자리가 그 값이 돼서,
출력하면 트루가 나와요.
보이드는 돌려주는 값이 없다는 뜻이에요.
이제 생성자예요.
지금까지는 객체를 만든 뒤
필드에 하나씩 값을 넣었죠.
생성자를 만들면 뉴 할
때 바로 넣을 수 있어요.
생성자는 클래스와 이름이 같고,
반환 타입을 쓰지 않아요.
뉴 스튜던트에 민수와 팔십오를 넘기면,
생성자가 실행돼서 한 줄로 객체가 완성돼요.
생성자 안의 디스는 지금 이 객체,
자기 자신을 가리켜요.
매개변수 이름이 필드와 같으면,
그냥 네임은 매개변수를 뜻해요.
그래서 디스 닷 네임은 이 객체의 필드,
네임은 넘겨받은 값이죠.
디스를 빼고 네임 이퀄 네임이라고 쓰면,
매개변수에 자기 값을 다시 넣을 뿐이라,
필드는 널과 영으로 남아요.
그럼 지난 시간엔 생성자 없이
어떻게 뉴 스튜던트를 했을까요?
클래스에 생성자가 하나도 없으면,
자바가 기본 생성자를 자동으로 넣어 줘요.
기본 생성자는 매개변수가 없고,
중괄호 안이 비어 있는 생성자예요.
그래서 빈 괄호로 객체를
만들 수 있었던 거예요.
주의할 점!
생성자를 직접 만들면 기본
생성자는 자동으로 생기지 않아서,
뉴 스튜던트 빈 괄호가 컴파일 오류가 나요.
빈 괄호로도 만들고 싶다면,
매개변수 없는 생성자를
하나 더 만들면 돼요.
이렇게 이름이 같은 생성자를 여러
개 두는 것을 오버로딩이라고 해요.
정리하면, 메소드는 클래스 안의 동작,
점으로 호출하고,
매개변수로 값을 받고,
리턴으로 결과를 돌려줘요.
생성자는 클래스와 이름이
같고 반환 타입이 없어요.
디스는 객체 자기 자신,
기본 생성자는 자동으로
들어가는 빈 생성자인데,
생성자를 직접 만들면 생기지 않아요.
구독과 좋아요 부탁드립니다!
