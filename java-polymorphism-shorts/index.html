자바 입문 다형성 정리
JAVA 입문 · 열네 번째

다형성

업캐스팅 · 다운캐스팅
STEP 1 · 부모 타입에 자식 객체

Person 에 Student 를

업캐스팅 (자식 → 부모 타입)

Person p = new Student(
"민수", 85);
Student→Person
Student 는 Person 이니까
자동으로 담긴다
STEP 1-1 · 누구의 hello?

실제 객체가 결정

오버라이딩한 메소드는 실제 객체 기준

Person p = new Student(
"민수", 85);
p.hello();
p.hello() 실행 결과
학생 민수 안녕
변수 타입Person
실제 객체Student← 이것이 실행
STEP 2 · 배열로 한 번에

한 배열, 다른 결과

같은 호출, 객체마다 다르게

Person[] people = {
new Student("민수", 85),
new Teacher("서준")
};
for (Person p : people) {
p.hello();
}
실행 결과
학생 민수 안녕
서준 선생님 안녕
다형성 = 여러 형태
같은 hello(), 객체마다 다른 결과
STEP 2-1 · 매개변수로

메소드 하나로 모두

Person 을 받으면 자식 모두 OK

static void greet(Person p) {
p.hello();
}
greet(new Student("민수", 85));
greet(new Teacher("서준"));
실행 결과
학생 민수 안녕
서준 선생님 안녕
STEP 3 · 부모 타입의 한계

p.score 는 오류

Person 에는 score 가 없다

Person p = new Student(
"민수", 85);
System.out.println(p.score);
컴파일 오류
cannot find symbol
쓸 수 있는지는 변수 타입이 결정
STEP 4 · 다운캐스팅

다시 Student 로

다운캐스팅 (부모 → 자식 타입)

if (p instanceof Student) {
Student s = (Student) p;
System.out.println(
s.score);
}
실행 결과
85
줄여 쓰기 (Java 16+)
if (p instanceof Student s)
STEP 4-1 · 잘못된 캐스트

실행 중 오류

컴파일은 OK, 실행하면 오류

Person p = new Teacher("서준");
Student s = (Student) p;
실행 오류
Exception in thread "main"
java.lang.ClassCastException:
class Teacher cannot be cast to class Student
캐스트 전에 instanceof 로
먼저 확인!
STEP 5 · 인터페이스 타입

Studyable 로 담기

구현했으니 같은 타입

Studyable[] list = {
new Student("민수", 85),
new Teacher("서준")
};
for (Studyable x : list) {
x.study();
}
실행 결과
민수 공부 중
서준 공부 중
Person 자식이라서가 아니라
Studyable 구현 덕분
정리

다형성 6가지

1부모 타입 ← 자식 객체
2오버라이딩 → 실제 객체 기준
3배열·매개변수 하나로
4부모 타입은 자식 것 ✗
5instanceof → 다운캐스팅
6인터페이스 타입도 똑같이
