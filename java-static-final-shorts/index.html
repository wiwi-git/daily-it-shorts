static · final · 상수
STEP 1 · static 필드

객체마다? 모두 함께?

static 을 붙이면 클래스에 하나

score인스턴스 필드(객체마다 따로)
countstatic 필드클래스에 하나 · 모두 함께
class Student {
String name;
int score;
static int count;
Student(String name,
int score) {
this.name = name;
this.score = score;
count++;
}
}
STEP 1 · 함께 쓰는 필드

만들 때마다 count 증가

객체가 아니라 클래스 이름으로 사용

Student s1 = new Student(
"민수", 85);
Student s2 = new Student(
"지영", 92);
System.out.println(
Student.count);
실행 결과
2
Student.count 처럼 클래스 이름으로
STEP 2 · static 메소드

객체 없이 호출

static 메소드는 클래스 이름으로 부른다

static int getCount() {
return count;
}
System.out.println(
Student.getCount());
Student s1 = new Student(
"민수", 85);
Student s2 = new Student(
"지영", 92);
System.out.println(
Student.getCount());
실행 결과 (객체를 만들기 전 · 만든 후)
0
2
STEP 2-1 · 주의

static에서는 score 불가

객체 없이 실행되니 누구의 score?

static int getScore() {
return score;
}
컴파일 오류
non-static variable score cannot be referenced from a static context
main 도 static이라
객체를 만들어 점으로 사용
STEP 3 · final 변수

한 번 넣으면 끝

final 변수는 다시 대입할 수 없다

final int x = 10;
x = 20;
컴파일 오류
cannot assign a value to final variable x
값을 한 번만 넣을 수 있다
STEP 3 · final 필드

생성자에서 한 번만

final 필드는 한 번만 대입

class Student {
final String name;
int score;
Student(String name,
int score) {
this.name = name;
this.score = score;
}
}
s1.name = "철수";
컴파일 오류
cannot assign a value to final variable name
이름은 그대로 · 점수는 계속 변함
STEP 3-1 · 주의

final Student s

변수를 막을 뿐, 객체는 막지 않는다

final Student s = new Student(
"민수", 85);
s.score = 100;
System.out.println(s.score);
실행 결과
100
s = new Student(
"지영", 92);
컴파일 오류
cannot assign a value to final variable s
final은 변수를 고정 · 객체 내용은 변경 가능
STEP 4 · final 메소드

오버라이딩 금지

final 메소드는 자식이 고칠 수 없다

class Person {
final void hello() { … }
}
class Student extends Person {
void hello() { … }
}
컴파일 오류
hello() in Student cannot override hello() in Person
overridden method is final
부모 클래스의 final 메소드는 오버라이딩 불가
STEP 4-1 · final 클래스

상속 금지

final 클래스는 상속할 수 없다

final class Person { … }
class Student extends Person {
}
컴파일 오류
cannot inherit from final Person
자바의 String 도 final 클래스
public final class String
STEP 5 · static final 상수

60을 이름으로

static final 로 상수를 만든다

class Student {
static final int
PASS_SCORE = 60;
int score;
boolean isPass() {
return score >= PASS_SCORE;
}
}
score >= 60 → score >= PASS_SCORE
민수(85) 의 isPass() 결과
true
상수 이름은 대문자와 _ 로 쓴다
STEP 5-1 · 상수 재대입

상수는 못 바꾼다

final 이라 다시 대입하면 오류

Student.PASS_SCORE = 70;
컴파일 오류
cannot assign a value to static final variable PASS_SCORE
기준 점수는 한 곳에서만 정한다
정리

static · final 6가지

1static 필드 = 모두가 함께 하나
2static 메소드 = 객체 없이 호출
3static에서 인스턴스 필드 ✕
4final 변수·필드 = 한 번만 대입
5final 메소드·클래스 = 변경 금지
6static final = 상수 (대문자)
