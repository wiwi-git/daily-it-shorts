static · final · 상수
STEP 1 · static 필드

객체마다? 모두 함께?

static 을 붙이면 클래스에 하나

score인스턴스 필드(객체마다 따로)
countstatic 필드클래스에 하나 · 모두 함께
class Student {
String name;
int score;
static int count;
Student(String name,
int score) {
this.name = name;
this.score = score;
count++;
}
}
STEP 1 · 함께 쓰는 필드

만들 때마다 count 증가

객체가 아니라 클래스 이름으로 사용

Student s1 = new Student(
"민수", 85);
Student s2 = new Student(
"지영", 92);
System.out.println(
Student.count);
실행 결과
2
Student.count 처럼 클래스 이름으로
STEP 2 · static 메소드

객체 없이 호출

static 메소드는 클래스 이름으로 부른다

static int getCount() {
return count;
}
System.out.println(
Student.getCount());
Student s1 = new Student(
"민수", 85);
Student s2 = new Student(
"지영", 92);
System.out.println(
Student.getCount());
실행 결과 (객체를 만들기 전 · 만든 후)
0
2
STEP 2-1 · 주의

static에서는 score 불가

객체 없이 실행되니 누구의 score?

static int getScore() {
return score;
}
컴파일 오류
non-static variable score cannot be referenced from a static context
main 도 static이라
객체를 만들어 점으로 사용
STEP 3 · final 변수

한 번 넣으면 끝

final 변수는 다시 대입할 수 없다

final int x = 10;
x = 20;
컴파일 오류
cannot assign a value to final variable x
값을 한 번만 넣을 수 있다
STEP 3 · final 필드

생성자에서 한 번만

final 필드는 한 번만 대입

class Student {
final String name;
int score;
Student(String name,
int score) {
this.name = name;
this.score = score;
}
}
s1.name = "철수";
컴파일 오류
cannot assign a value to final variable name
이름은 그대로 · 점수는 계속 변함
STEP 3-1 · 주의

final Student s

변수를 막을 뿐, 객체는 막지 않는다

final Student s = new Student(
"민수", 85);
s.score = 100;
System.out.println(s.score);
실행 결과
100
s = new Student(
"지영", 92);
컴파일 오류
cannot assign a value to final variable s
final은 화살표를 고정 · 객체 내용은 변경 가능
