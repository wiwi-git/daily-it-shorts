STEP 1 · 멈춤 신호

volatile boolean

volatile = 다른 스레드가 바꾼 값을 보게
없으면 못 보고 계속 돌 수도 있어요

static volatile boolean stop;
Thread t = new Thread(() -> {
try {
while (!stop) {
System.out.println("작업 중");
Thread.sleep(200);
}
} catch (
InterruptedException e) {}
System.out.println("작업 끝");
});
이어서 main
t.start();
Thread.sleep(1000);
stop = true;

STEP 3 · 예외 삼키지 않기

빈 catch {}

예외가 나면 인터럽트 상태가 지워진다

main은 STEP 2와 같음 · t.interrupt()
Thread t = new Thread(() -> {
while (!Thread.currentThread()
.isInterrupted()) {
System.out.println("작업 중");
try { Thread.sleep(200); }
catch (
InterruptedException e) {}
}
System.out.println("작업 끝");
});

스레드 멈추기

1stop()은 쓰지 않기 → 멈춰 달라고 요청
2멈춤 신호에는 volatile
3interrupt()는 자는 스레드도 깨운다
4예외를 삼키지 말고 interrupt()로 되살리기
5데몬 스레드는 일반 스레드와 함께 끝난다
