👍 구독 · 좋아요
자바 입문 두 번째, 변수!
변수의 개념부터 선언과 대입, 정수와 실수,
문자와 문자열까지 정리해 드립니다.
변수는 값을 저장해 두는,
이름 붙은 공간이에요.
상자에 이름표를 붙이고 값을
넣는다고 생각하면 쉬워요.
인트 에이지 이퀄 이십은,
정수를 담는 에이지라는 상자에
이십을 넣으라는 뜻입니다.
이제 에이지라는 이름으로
값을 꺼내 쓸 수 있어요.
변수를 만드는 것을 선언,
값을 넣는 것을 대입이라고 합니다.
인트 스코어 세미콜론으로 선언하고,
스코어 이퀄 구십으로 대입해요.
여기서 이퀄은 같다가 아니라,
오른쪽 값을 왼쪽 변수에
저장한다는 뜻이에요.
다시 대입하면 새 값으로 바뀌어서,
구십오가 출력돼요.
선언과 동시에 값을 넣는
것은 초기화라고 해요.
주의할 점도 있어요.
메서드 안의 지역 변수는 값을 넣기
전에 쓰면 컴파일 오류가 납니다.
같은 이름으로 두 번 선언해도 오류예요.
그리고 변수 이름은
숫자로 시작할 수 없어요.
정수 타입은 바이트, 쇼트, 인트, 롱 네 가지로,
크기에 따라 범위가 달라요.
기본은 인트로, 약 플러스 마이너스 이십일억까지 담습니다.
더 큰 수는 롱을 쓰고,
숫자 뒤에 대문자 엘을 붙여요.
엘 없이 삼십억을 쓰면,
인트 범위를 넘어서 컴파일 오류가 납니다.
실수 타입은 플로트와 더블이 있고,
기본은 더블입니다.
소수점이 있는 숫자는 더블로 취급돼서,
플로트에 넣으려면 뒤에 에프를 붙여야 해요.
그리고 정수끼리 나누면
소수점 아래가 버려집니다.
칠 나누기 이는 삼,
칠 나누기 이 점 영은 삼 점 오가 돼요.
문자 타입 차는 문자 하나를 저장하고,
작은따옴표로 감쌉니다.
에이, 가, 칠처럼 딱 한 글자만 들어가요.
큰따옴표로 감싸면 문자열이
되어서 차에 넣을 수 없어요.
그리고 문자는 내부적으로
숫자 코드로 저장돼서,
대문자 에이를 인트로 바꿔
출력하면 육십오가 나옵니다.
여러 글자는 대문자 에스로
시작하는 문자열 타입 스트링에,
큰따옴표로 감싸서 저장해요.
인트, 더블, 차 같은 기본형과 달리,
스트링은 클래스로 만든 참조형이에요.
더하기 기호로 문자열을
이어 붙일 수 있는데,
문자열과 숫자를 더하면
숫자도 글자로 붙어요.
그래서 큰따옴표 일 더하기 이는 십이,
숫자 일 더하기 이는 삼이 됩니다.
정리하면, 변수는 이름 붙은 저장 공간,
선언과 대입으로 값을 넣고,
정수는 인트와 롱,
실수는 더블과 플로트,
문자는 작은따옴표 차,
문자열은 큰따옴표 스트링.
도움이 됐다면 구독과 좋아요 부탁드립니다!
