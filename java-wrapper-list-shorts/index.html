STEP 2 · 오토박싱·언박싱

자동으로 바뀐다

넣을 때 감싸고, 쓸 때 풀고

Integer n = 85; // 오토박싱
int m = n + 1; // 언박싱
System.out.println(m);
int k = Integer.parseInt("92");
System.out.println(k + 1);
실행 결과
86
93
int→Integer 오토박싱
Integer→int 언박싱
parseInt : 문자열 → 숫자
STEP 2-1 · null 언박싱

null 은 풀 수 없다

래퍼는 객체라서 null 가능

Integer n = null; // OK
int m = n; // 언박싱
실행 오류
java.lang.NullPointerException:
Cannot invoke "java.lang.Integer.intValue()" because "n" is null
컴파일은 되고 실행 중 오류
null 이 들어올 수 있으면 조심!
STEP 3 · ArrayList

크기를 안 정한다

꺾쇠로 담을 타입 정하기 = 제네릭

// 뒤 주석 = 그 줄을 실행한 결과 값
import java.util.ArrayList;
ArrayList<String> names =
new ArrayList<>();
names.add("민수");
names.add("서준");
names.add("지우");
// names → [민수, 서준, 지우]
names.size(); // 3
names.get(0); // 민수
<String> → 문자열만 들어간다
오른쪽 <> 는 비워도 OK

STEP 4 · set · remove · contains

지우면 당겨진다

뒤 칸이 한 칸씩 앞으로

names.add("하은");
// names → [민수, 서준, 지우, 하은]
names.remove(0);
// names → [서준, 지우, 하은]
names.get(0); // 서준
names.contains("민수"); // false
names.set(0, "민수");
// names → [민수, 지우, 하은]
[0][1][2][3]remove 전민수서준지우하은remove 후서준지우하은
set = 덮어쓰기 (서준 → 민수)
끼워 넣는 게 아님
STEP 5 · List<Integer>

점수는 Integer 로

< > 안엔 기본 타입 ✗

ArrayList<int> scores;
컴파일 오류
unexpected type
required: reference
import java.util.List;
List<Integer> scores =
new ArrayList<>();
scores.add(85);
scores.add(92);
scores.add(78);
int sum = 0;
for (int s : scores) sum += s;
// sum → 255
변수는 List 타입 (업캐스팅)
STEP 5-1 · remove(1) 의 함정

1 은 값? 칸?

인덱스를 받는 remove 가 먼저

// scores → [85, 92, 78]
scores.remove(1);
// scores → [85, 78]
값 1 이 아니라 1번 칸(92)을 지운다
scores.remove(
Integer.valueOf(85));
// scores → [92, 78]

래퍼 클래스와 List

1래퍼 = 기본 타입을 객체로
2오토박싱·언박싱 (null 주의)
3add · get · size()
4remove → 뒤 칸이 당겨짐
5< > 안엔 기본 타입 ✗ → Integer
6변수는 기본적으로 List 타입
7remove(1) = 1번 칸

자바 입문 열일곱 번째,
래퍼 클래스와 리스트!
학생 점수를 모으고 싶은데,
몇 명일지 모른다면 어떻게 할까요?
배열은 크기가 고정이라 곤란하죠.
오늘 래퍼 클래스와 리스트로 해결해 볼게요.
래퍼 클래스는 기본 타입 값을
객체로 감싼 클래스예요.
인트는 인티저, 차는 캐릭터로 이름이 바뀌고,
나머지는 더블, 불리언처럼 첫 글자만 대문자로 쓰면 돼요.
값은 그대로 담을 수 있어요.
인티저 엔에 팔십오를 바로 넣으면,
자바가 알아서 객체로 감싸 줘요.
이게 오토박싱이에요.
반대로 엔 더하기 일처럼
계산하면 다시 인트로 풀리는데,
이건 언박싱이에요.
그래서 팔십육이 나와요.
인티저 닷 파스인트는 문자열
구십이를 숫자로 바꿔 줘서,
더하기 일 하면 구십삼이에요.
래퍼는 객체라서 널도 담을 수 있어요.
그런데 널을 인트에 넣으면,
풀어낼 값이 없어서 실행 중에
널 포인터 익셉션이 나요.
컴파일은 되니까 더 조심해야 해요.
이제 리스트예요.
자바 유틸의 어레이리스트를 임포트하고,
꺾쇠 안에 담을 타입을 적어요.
이렇게 타입을 정하는
문법을 제네릭이라고 하는데,
스트링으로 정했으니
문자열만 넣을 수 있어요.
오른쪽 꺾쇠는 비워 둬도 되고,
크기는 정하지 않아요.
애드로 민수, 서준,
지우를 넣으면 순서대로 담기고, 사이즈는 삼,
겟 영은 민수예요.
인덱스가 영부터인 건 배열과 같아요.
그래서 겟 삼은 범위를 벗어나,
인덱스 아웃 오브 바운즈 익셉션이 나요.
배열의 대괄호 영은 겟 영,
닷 렝스는 사이즈로 바꿔 쓰면 돼요.
하은을 애드하면 네 명이 되죠.
크기가 알아서 늘어나요.
이제 리무브 영으로 민수를 지우면,
뒤에 있던 칸이 한 칸씩 앞으로 당겨져서,
겟 영은 서준이 돼요.
컨테인즈로 민수가 있는지 물으면 폴스,
셋 영은 영번 칸의 서준을 민수로 바꿔요.
끼워 넣는 게 아니라 덮어써요.
이제 점수를 모아 볼게요.
꺾쇠 안에는 기본 타입을 쓸 수 없어서,
어레이리스트 인트는 컴파일 오류예요.
그래서 인티저를 써요.
애드 팔십오처럼 인트를 넣어도 오토박싱되고,
향상된 포문으로 꺼내면
언박싱돼서 합계는 이백오십오예요.
변수 타입은 기본적으로
인터페이스인 리스트로 받아요.
업캐스팅이죠.
숫자 리스트에는 함정이 하나 있어요.
리무브 일은 값 일이
아니라 일번 칸을 지워요.
인덱스를 받는 리무브가 먼저 선택되거든요.
그래서 구십이가 지워져요.
값으로 지우려면 인티저 닷
밸류오브로 객체를 만들어 넘기면,
팔십오가 지워져요.
정리할게요.
래퍼 클래스는 기본 타입을 객체로 감싸요.
오토박싱과 언박싱은 자동이지만,
널은 조심하세요.
어레이리스트는 애드, 겟, 사이즈로 쓰고,
리무브하면 뒤 칸이 당겨져요.
꺾쇠 안에는 기본 타입을
못 써서 인티저를 쓰고,
변수는 기본적으로 리스트 타입으로 받아요.
마지막으로, 리무브 일은 일번 칸이에요.
다음 편은 람다식이에요.
구독과 좋아요 부탁드려요!
