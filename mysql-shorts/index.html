SQL = 데이터베이스에게 일을 시키는 언어

SQL의 5가지 종류

DQL조회SELECT
DML데이터 변경INSERT · UPDATE · DELETE
DDL구조 정의CREATE · ALTER · DROP
TCL트랜잭션COMMIT · ROLLBACK
DCL권한GRANT · REVOKE
중요도는 전혀 같지 않다!
1위DQL

SELECT

실무 쿼리의 대부분은 조회

SELECT name, price
FROM products
WHERE price > 10000
ORDER BY price DESC;
데이터 확인리포트장애 분석
1위DQL+

JOIN · GROUP BY

여러 테이블 연결 + 집계

SELECT u.name, COUNT(o.id) AS cnt
FROM users u
JOIN orders o ON o.user_id = u.id
GROUP BY u.name;
일별 매출회원별 주문 수
2위DML

INSERT · UPDATE · DELETE

데이터를 추가 · 수정 · 삭제

INSERT INTO users (name)
VALUES ('kim');
UPDATE users SET name = 'lee'
WHERE id = 1;
DELETE FROM users WHERE id = 1;
⚠ WHERE 빠뜨리면 테이블 전체가 바뀜
실행 전 같은 조건으로 SELECT 먼저!
3위DDL

CREATE · ALTER · DROP

테이블 구조를 정의

CREATE TABLE users (
id INT PRIMARY KEY AUTO_INCREMENT,
name VARCHAR(50)
);
ALTER TABLE users
ADD email VARCHAR(100);
CREATE INDEX idx_name ON users(name);
DROP TABLE users;
⚠ 잘못 쓰면 되돌리기 어려움
4위TCL

COMMIT · ROLLBACK

전부 성공 or 전부 취소

START TRANSACTION;
UPDATE acct SET bal = bal - 1000
WHERE id = 1;
UPDATE acct SET bal = bal + 1000
WHERE id = 2;
COMMIT; -- 실패 시 ROLLBACK;
MySQL 기본값 autocommit = 1
롤백하려면 트랜잭션부터 열기
5위DCL

GRANT · REVOKE

사용자 권한 관리

GRANT SELECT, INSERT ON shop.*
TO 'dev'@'%';
REVOKE INSERT ON shop.*
FROM 'dev'@'%';
주로 DBA · 인프라 담당개발자는 마지막에

마이에스큐엘 SQL,
뭐부터 배워야 할까요?
공부한 시간 대비 실무에서
가장 많이 써먹는,
가성비 순서로 딱 정리해 드립니다.
SQL은 데이터베이스에게
일을 시키는 언어입니다.
크게 다섯 종류로 나뉘는데요,
조회하는 DQL,
데이터를 바꾸는 DML,
구조를 만드는 DDL,
트랜잭션을 다루는 TCL,
그리고 권한을 다루는 DCL입니다.
그런데 이 다섯 개,
중요도가 전혀 같지 않습니다.
가성비 1위, 셀렉트, DQL입니다.
실무 쿼리의 대부분이 바로 조회예요.
셀렉트로 컬럼을 고르고,
프롬으로 테이블을,
웨어로 조건을 걸고,
오더 바이로 정렬하면 끝.
이것만 알아도 데이터 확인, 리포트,
장애 분석까지 바로 할 수 있습니다.
여기에 조인과 그룹 바이까지
익히면 진짜 무기가 됩니다.
조인은 여러 테이블을 키로 연결하고,
그룹 바이는 카운트나 썸으로 집계하죠.
일별 매출, 회원별 주문 수 같은 질문에 쿼리
한 줄로 답할 수 있습니다.
2위, 데이터를 바꾸는 DML.
인서트로 추가하고,
업데이트로 수정하고,
딜리트로 삭제합니다.
딱 세 개라 금방 외우지만
주의할 점이 하나 있어요.
업데이트와 딜리트에 웨어를 빼먹으면,
테이블 전체가 바뀝니다.
실행 전에 같은 조건으로
셀렉트부터 해 보는 습관, 꼭 들이세요.
3위, 구조를 만드는 DDL.
크리에이트 테이블로 테이블을 만들고,
얼터로 컬럼을 추가하거나 바꾸고,
드롭으로 지웁니다.
인덱스를 만드는 것도 여기 속하죠.
자주 쓰진 않지만,
한 번 잘못 쓰면 되돌리기
어려우니 원리는 꼭 알아 두세요.
4위, 트랜잭션을 다루는 TCL.
스타트 트랜잭션으로 시작해서, 성공하면 커밋,
실패하면 롤백.
계좌 이체처럼 여러 작업을 전부
성공하거나 전부 취소해야 할 때 씁니다.
참고로 마이에스큐엘은 기본이 오토 커밋이라,
롤백하려면 트랜잭션을 먼저 열어야 해요.
5위, 권한을 다루는 DCL.
그랜트로 권한을 주고,
리보크로 회수합니다.
중요하지만 주로 DBA나
인프라 담당이 하는 일이라,
개발자라면 가장 나중에 봐도 충분합니다.
정리하면, 셀렉트, DML, DDL, TCL,
DCL 순서입니다.
오늘은 셀렉트부터 시작해 보세요.
도움이 됐다면 구독과 좋아요 부탁드립니다!
