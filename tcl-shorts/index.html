STEP 1-1

COMMIT

커밋하는 순간 한꺼번에 확정

START TRANSACTION;
UPDATE accounts
SET balance = balance - 10000
WHERE name = 'kim';
UPDATE accounts
SET balance = balance + 10000
WHERE name = 'lee';
COMMIT;
결과 · 합계 60000 그대로

kim40000
lee20000

SAVEPOINT

일부만 되돌리기

START TRANSACTION;
UPDATE accounts
SET balance = balance - 10000
WHERE name = 'kim';

STEP 5-1 · 마무리

끝은 COMMIT

ROLLBACK TO는 트랜잭션을 끝내지 않음

이어서 · 리에게 제대로 입금

COMMIT;

DDL은 자동 커밋

ROLLBACK;

👍 구독 · 좋아요
이체하다 서버가 멈추면,
내 돈은 어떻게 될까요?
트랜잭션의 커밋과 롤백,
한 번에 정리해 드립니다.
킴이 리에게 만 원을 보내려면,
킴의 잔액을 빼고 리의 잔액을
더하는 업데이트가 두 번 필요해요.
그런데 첫 번째만 실행되고 멈추면,
만 원이 그대로 사라집니다.
그래서 여러 작업을 하나로
묶는 트랜잭션을 씁니다.
모두 성공하면 커밋으로 전부 반영하고,
문제가 생기면 롤백으로 전부 취소하죠.
이 성질을 원자성이라고 해요.
단, 오류가 났다고 저절로 전부 취소되진 않으니,
롤백은 직접 실행해야 해요.
스타트 트랜잭션으로 시작해
두 업데이트를 실행하고,
커밋하면 그때 한꺼번에 확정됩니다.
킴은 4만 원, 리는 2만 원이 되죠.
중간에 문제가 생기면 커밋 대신 롤백.
트랜잭션 안에서 한 변경이 모두 취소되고,
시작하기 전 상태로 돌아갑니다.
또, 커밋하기 전의 변경은 기본 설정에서
다른 세션에 보이지 않아요.
다른 세션 B에서 조회하면 킴의
잔액은 아직 5만 원이죠.
계산 도중의 어정쩡한 값을
남이 읽지 않는 거예요.
주의할 점.
마이에스큐엘은 기본이 오토 커밋이라,
트랜잭션을 열지 않고 실행한
업데이트는 바로 확정돼요.
이 상태에서는 롤백해도 되돌아가지 않습니다.
세이브포인트로 일부만 되돌릴 수도 있어요.
킴의 출금 뒤에 세이브포인트를 찍고,
리에게 10만 원을 잘못 더했다면,
롤백 투로 그 지점까지만 취소합니다.
킴의 출금은 남지만,
아직 커밋 전이에요.
롤백 투는 트랜잭션을 끝내지 않아요.
이어서 리에게 만 원을 제대로
더하고 커밋해야 이체가 끝납니다.
킴은 4만 원, 리는 2만 원,
합계 6만 원 그대로죠.
마지막으로, 트랜잭션 도중에 얼터
같은 DDL을 실행하면,
그 전까지의 작업이 자동으로 커밋돼요.
그리고 트랜잭션을 오래 열어 두면 같은
행을 고치려는 다른 작업이 기다리게 되니, 짧게 끝내세요.
정리하면, 스타트 트랜잭션으로 묶고, 커밋으로 확정,
롤백으로 취소.
오토 커밋과 세이브포인트,
DDL의 자동 커밋까지.
이것만 알면 트랜잭션 기본은 끝!
도움이 됐다면 구독과 좋아요 부탁드립니다!
