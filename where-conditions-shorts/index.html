STEP 5 · NULL

IS NULL

NULL은 =로 비교 불가

✗ 항상 결과 없음
WHERE category = NULL;
✓ NULL 찾기 · 제외하기
WHERE category IS NULL;
WHERE category IS NOT NULL;
⚠ NOT IN 목록에 NULL → 결과 없음
WHERE category
NOT IN ('book', NULL);

같다는 이퀄 하나,

문자열은 작은따옴표로 감쌉니다.
카테고리가 북인 상품을 고르면,
SQL 입문서와 SQL 문제집이 나오죠.

3천 원에서 1만 원 사이를 고르면,

비트윈은 양 끝 값을 포함하거든요.
